5 进阶主题

本章深入引擎的九个高级方向，每节都附可直接运行的完整样例。按需直达：

5.1 洛蒂动画引擎

JSON 描述 → prepare() 烘焙 → 播放的完整链路：操作类型语义、easing / path 曲线增强、C++ 三档用法、C ABI CreateAnimation 全流程，以及烘焙、时间驱动、共享实例等机制与陷阱。

5.2 多视口与多窗口

一进程多 UI 实例：视图层次与能力位、单窗口双视口样例、双实例跨窗口通信样例、C ABI 配置结构，以及 K1–K8 隔离性保证。

5.3 非可视化控件

HotReloader 热重载、DataContext 数据绑定、LayoutParser 自定义 handler、FocusManager 可编程焦点、ResourceProvider 资源链——五个功能控件的完整用法。

5.4 纯 C ABI 程序化构建

不依赖 JSON 布局与 Binding 层，直接用扁平属性接口搭建容器树、菜单与回调，并读取 UIEventData 事件负载的完整工程样例。

5.5 控件缩放（Scale）

xScale / yScale 初始缩放系数：缩放模型与父子累积语义、C++ Binding 与 C ABI 创建参数、JSON "scale" 声明，以及与 LuotiAni 动画、Actor scaleType 的区别。

5.6 视口画布缩放（Canvas Scale）

设计分辨率适配：off / fit / stretch 三种模式、基准画布与 JSON viewport 键、运行时切换（setEnumProperty / C ABI / Binding）、字号随复合重建与可见性过滤、坐标逆变换与字体缓存统计。

5.7 拖拽框架（Drag & Drop）

控件级通用拖拽：draggable / droppable / reorderable 注册，语义化载荷与落点（tree 节点 / list 行 / tab 页自动填充），drag-start / drag-over / drop / drag-end 事件与默认视觉，tree / list / tab 内置换序，以及 OS 文件拖入（SetDropFileCallback）。

5.8 使用其它后端（SFML / raylib）

同一份业务代码切换 SFML / raylib 后端：编译期与运行时选择、后端能力位与条件化渲染、后端差异配置键（vsync / swap-ratio 等）与已知差异对照。

5.9 嵌入到你的逻辑回路中

把引擎接进宿主主循环：Embedded / AppCallbacks / 事件泵手工驱动 / 显式 LoadLibrary 四种集成模式、与自有对象模型对接、多实例调度与自动退出参数。
