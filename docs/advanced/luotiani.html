5.1 全面掌握洛蒂动画引擎

LuotiAni 是引擎内置的关键帧动画系统：JSON 描述动画 → prepare() 逐帧烘焙为离屏帧贴图 → 播放时按墙钟毫秒查表绘制。烘焙完成后 JSON 不再参与运行，运行时零插值零计算——这是它与逐帧实时求值的动画系统的本质区别。

5.1.1 动画描述文件（JSON）

官方资源 animations/rotateBtn/rotateBtn.jsonc（256×256 画布、60 帧的旋转按钮）是标准结构范本：

{
    "overview": {
        "version": "0.0.1",
        "name": "rotate button animation",
        "view": { "width": 256, "height": 256 },   // 画布尺寸：超出部分裁剪
        "frameRate": 60,                            // 不得为 0
        "totalFrames": 60,
        "loop": true                                // 必填（严格解析，缺失抛异常）
    },
    "layers": [
        {
            "name": "rotate button",
            "type": "image",                        // image / shape / text
            "src": "animations/rotateBtn/rotateBtn.svg",   // 资源包内路径
            "width": 256, "height": 256,            // 缺省则保持图片原始尺寸
            "opacity": 100,                         // 图层级默认不透明度（0~100）
            "blendMode": "blend",                   // normal/additive/modulate/blend/multiply
            "keyFrames": [
                { "frame": 0, "operation": [
                    { "type": "translate", "tx": 0, "ty": 0 },
                    { "type": "scale", "sx": 1, "sy": 1 },
                    { "type": "rotate", "angle": 0, "cx": 128, "cy": 128 },
                    { "type": "opacity", "opacity": 100 },
                    { "type": "visible", "visible": true }
                ]},
                { "frame": 59, "operation": [
                    { "type": "rotate", "angle": 360, "cx": 128, "cy": 128 }
                ]}
            ]
        }
    ]
}
操作类型字段语义
opacityopacity（0~100）百分比覆盖（内部转 0~255）
rotateangle, cx, cy角度累加，绕 (cx, cy) 旋转中心
scalesx, sy相对上一关键帧累乘
translatetx, ty相对上一关键帧增量累加
visiblevisible可见性覆盖
未列出的属性沿用上一关键帧的到达值；最后一个关键帧之后的帧保持到达值（carry-over）。第 0 帧关键帧必须存在（缺失直接抛异常）。

5.1.2 缓动与路径（easing / path）

easing 写在目标关键帧的操作上，对段内所有属性的插值统一做时间重映射；path 仅作用于 translate 的段内位置轨迹，控制点相对段起点。引擎级演示动画（test_luotiani 的 tl_demo）完整展示了两种能力：

{
    "overview": { "name": "demo", "version": "0.0.1",
                  "view": { "width": 256, "height": 256 },
                  "frameRate": 30, "totalFrames": 60, "loop": true },
    "layers": [
        { "name": "layer1", "type": "image",
          "src": "animations/rotateBtn/rotateBtn.svg",
          "opacity": 100, "blendMode": "normal",
          "keyFrames": [
            { "frame": 0, "operation": [
                { "type": "translate", "tx": 0, "ty": 0 },
                { "type": "rotate", "angle": 0, "cx": 128, "cy": 128 },
                { "type": "opacity", "opacity": 100 } ] },
            { "frame": 30, "operation": [
                { "type": "translate", "tx": 120, "ty": 60,
                  "easing": "ease-in-out",
                  "path": { "type": "bezier", "c1x": 80, "c1y": -120, "c2x": 200, "c2y": 150 } },
                { "type": "rotate", "angle": 180, "cx": 128, "cy": 128 },
                { "type": "opacity", "opacity": 100 } ] },
            { "frame": 60, "operation": [
                { "type": "translate", "tx": -120, "ty": -60, "easing": "ease-in-out" },
                { "type": "rotate", "angle": 180, "cx": 128, "cy": 128 },
                { "type": "opacity", "opacity": 100 } ] }
          ] }
    ]
}
easing 值说明
cubic-bezier(x1,y1,x2,y2)自定义贝塞尔（x 须在 [0,1]）；未知值回退 linear
ease-in / ease-out / ease-in-out三次缓入 / 缓出 / 缓入缓出
linear（缺省）线性插值
quad / sine / cubic二次 / 正弦 / 三次多项式曲线
path 类型字段说明
bezierc1x/c1y（二次）、c2x/c2y（三次）控制点相对段起点
catmull-rompoints多点平滑过点曲线
parabolavx, vy初速物理轨迹，重力由终点反解，t=1 精确到达终点

5.1.3 C++ 完整用法

独立动画控件（Builder 链式，一步到位）：

auto ani = LuotiAniBuilder(BENCH)
    .loadAniDesc(string("animations/rotateBtn/rotateBtn.jsonc"))  // 资源根相对路径
    .setRect(SRect(20, 20, 256, 256))
    .prepare()                 // 逐帧烘焙（重复调用早退）
    .setAutoStart()            // 内部调 play()
    .build();
ani->create();
BENCH->addControl(ani);

引擎级加载 / 播放 / 调试接口（精细控制）：

auto ani = make_shared<LuotiAni>(BENCH);
ani->loadAniDesc(fs::path("animations/rotateBtn/rotateBtn.jsonc")); // 失败 throw（需 try/catch）
ani->prepare();               // 烘焙全部帧
ani->play();                  // 复位帧到 0 重播
// 播放控制
ani->pause();                 // 停住（保持当前帧）
ani->resume();                // 从暂停处继续（区别于 play 的重播语义）
ani->setFrame(30);            // 跳帧（未 prepare / 越界忽略）
ani->setLoop(false);          // 到尾帧触发 AnimationEnded 事件并停止
// 调试：读中间帧插值结果与烘焙画布
LuotiAni::OpData d = ani->getFrameOpData(0 /*layer*/, 7 /*frame*/);
float alpha = d.opacity;                        // 0~255 域
SharedSurface canvas = ani->getFrameCanvas(7);  // 该帧合成后的离屏画布
ani->draw(7, x, y, alpha);                      // 绘制指定帧（不推进播放）

挂载到按钮（按钮自带动画外观）：

auto rotateAni = LuotiAniBuilder(BENCH)
    .loadAniDesc(string("animations/rotateBtn/rotateBtn.jsonc"))
    .prepare().setAutoStart().build();
auto btn = ButtonBuilder(nullptr, SRect(530, 50, 120, 50))
    .setLuotiAni(rotateAni)
    .setTransparent(true)
    .setOnClick([](shared_ptr<Button> b) { /* ... */ })
    .build();
btn->create();
BENCH->addControl(btn);

布局 JSON 中挂动画（luotiAni 键，挂树后自动延迟 prepare；加 "playing": true 则 prepare 后 自动播放，缺省不播——播放经 SetBool("playing")=1 启动；相对路径按 exe 所在目录解析）：

{ "type": "button", "id": "aniBtn",
  "rect": { "x": 200, "y": 532, "w": 100, "h": 40 },
  "caption": "Animated", "font-size": 14,
  "luotiAni": "assets/animations/rotateBtn/rotateBtn.jsonc",
  "events": { "onClick": "onAniBtnClick" } }

5.1.4 C ABI 调用（CreateAnimation）

// 创建：w/h 传 0 回退到 JSON overview.view 画布尺寸；失败返回 NULL
UIControlHandle ani = UICornerstone_CreateAnimation(g_inst, "tA3.jsonc", 60, 60, 256, 256, 1.0f, 1.0f);
UICornerstone_SetBool(g_inst, ani, "playing", 1);   // 播放（每次置 1 帧复位 0 重播）
UICornerstone_GetInt(g_inst, ani, "frame", &f);      // 读当前帧
UICornerstone_SetBool(g_inst, ani, "playing", 0);   // 暂停（帧停住）
UICornerstone_SetBool(g_inst, ani, "loop", 1);      // 循环
UICornerstone_SetInt(g_inst, ani, "frame", 8);      // 跳帧
// 换动画：重新走 加载→prepare→播放（状态重置）
UICornerstone_SetString(g_inst, ani, "animation", "animations/hero.jsonc");

动画按钮（C ABI CreateAnimatedButton / Binding CreateAnimatedButton）：动画作为内嵌资源挂到按钮 （不挂树、不响应鼠标、rect 为按钮局部坐标铺满按钮）。两个 scale 参数作用于按钮本身， 内嵌动画构造 scale 恒 1.0f——按钮缩放经 setParent 复合缩放自动传导到动画， 对动画再乘按钮系数会造成双重缩放（2x 按钮 → 4x 内容，见 5.5 控件缩放）。 JSON 布局等价写法 "luotiAni" 键（见上节）。播放控制与普通动画一致：SetBool("playing")。

5.1.5 机制细节与语义陷阱

  • 时间驱动：update() 用绝对墙钟毫秒推进帧（每帧毫秒 = 1000/frameRate），播放速度只与真实时间有关，与调用 update 的帧率无关（帧率低时一次跳多帧）；
  • 多实例共享烘焙：LuotiInstance(parent, shared_ptr<LuotiAni>, userId, ...) 共享同一份帧贴图，各实例独立推进；内存与 帧数×画布尺寸 成正比（60 帧 512×512 ≈ 63MB）；
  • 缩放校准：帧 Actor 非控件树成员，绘制当前帧前会校准缩放跟随父链（嵌套在 2x 缩放容器内动画也正确）；
  • 帧位图过滤：setFrameFilter(true) 双线性平滑（画布缩放 fit/stretch 下放大帧位图时推荐，见 5.6.8）、false 最近邻像素风；三后端经 RenderDevice::setTextureFilter 统一实现；
  • play() 总是复位帧到 0 重播；C ABI playing 每次置 1 都是重播（无暂停/继续状态机，暂停/继续用 playing=0/1 近似）；
  • setFrame 跳帧后首次 update 不复位计时会连跳；animation 属性只写不读；未 prepare 时置 playing=1 被拒绝；
  • 图层类型 shape/text 解析支持但烘焙跳过（无可见输出）；AnimationEnded 事件已触发但尚无 C ABI 回调链路。
