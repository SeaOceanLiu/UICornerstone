5.5 控件缩放（Scale）

所有控件都支持 初始缩放系数（xScale / yScale）：创建时传入，或通过 JSON 声明、运行时属性设置。 缩放作用于绘制内容——文字、线宽、贴图尺寸均按系数放大/缩小，而布局矩形（rect）保持不变。

5.5.1 缩放模型

缩放是控件的固有属性，遵循以下规则：

  • 内容缩放，布局不变：rect（x/y/w/h）仍决定命中测试与布局，只有绘制内容按系数缩放；
  • 父子继承：控件的实际缩放系数为其 自身系数 × 所有祖先系数（累积连乘）， 引擎内部以 xxScale / yyScale 表示；
  • 默认 1.0f：不传即原尺寸，所有 API 均以 1.0f 为默认；
  • X/Y 独立：x、y 两轴可分别设置，实现非等比缩放。

缩放与洛蒂动画（LuotiAni）的 scale 操作、以及Actor 的 scaleType（STRETCH / FIT_CENTER / CENTER_CROP / NONE）无关： 前者是动画时间轴上的贴图变换，后者是图片内容的适配模式，均不改变控件自身的缩放系数。

5.5.2 C++ Binding 用法

每个 Create* 工厂函数末尾都有可选参数 xScale, yScale（默认 1.0f，可省略）：

auto ui = UICornerstone::Create(...);

// 创建 2 倍内容缩放的按钮（宽高仍按原布局参与命中测试）
auto btn = ui->CreateButton("OK", 20, 20, 120, 36, 2.0f, 2.0f);

// 不传即原尺寸
auto lbl = ui->CreateLabel("标题", 24, 10, 10, 200, 40);
注意：C++ Binding 的缩放系数仅在创建时生效（运行时属性系统未挂接 xScale / yScale，SetFloat("xScale", ...) 无效）。运行时要改变缩放， 请用 JSON 布局的 "scale" 配合重新加载（见 5.5.4），或直接使用核心库原生 setScaleX / setScaleY 接口。

5.5.3 C ABI 用法

C ABI 的创建函数必须显式传参（C 接口无默认参数），保持原尺寸请传 1.0f, 1.0f：

UIControlHandle btn = UICornerstone_CreateButton(g_inst, "OK", 20, 20, 120, 36, 1.0f, 1.0f);

// 2 倍缩放
UIControlHandle big = UICornerstone_CreateLabel(g_inst, "标题", 24, 10, 10, 200, 40, 2.0f, 2.0f);

5.5.4 JSON 声明式用法

在控件 JSON 中声明 "scale" 对象（不写则默认 1.0）：

{
  "type": "button",
  "id": "btnOk",
  "x": 20, "y": 20, "w": 120, "h": 36,
  "scale": { "x": 2.0, "y": 2.0 }
}

解析时等价于调用 setScaleX / setScaleY；布局加载后仍可用属性系统在运行时调整。

5.5.5 典型场景

  • 高 DPI 界面：整棵 UI 树用同一系数创建，即全局放大；
  • 非等比适配：x/y 系数不同，模拟 2.5D 斜切观感（配合 luotiani 变换时注意叠加语义）；
  • 运行时动画：核心库原生 setScaleX / setScaleY 可在回调中改变系数； 若通过 Binding 使用，用 LoadLayout 重新加载带 "scale" 的 JSON 实现等效效果。
重要：内嵌动画的双重缩放陷阱——LuotiAni 经 setParent 继承按钮的复合缩放 （xxScale = 自身系数 × 父链连乘）。因此创建动画按钮时， 内嵌 LuotiAni 的构造 scale 必须传 1.0f, 1.0f，缩放只设置在按钮上 （C ABI UICornerstone_CreateAnimatedButton 与 JSON 布局 {"type":"button","luotiAni":...} 均按此约定）。 若动画再乘按钮系数，2x 按钮会把动画画成 4x。
提示：C ABI 创建函数的尾部两个参数即缩放系数，完整签名见附录 8 C ABI 速查表； C++ Binding 工厂签名见附录 11 C++ Binding 速查表。

5.5.6 缩放对照测试

缩放语义由三件套测试守护（同一三列布局：btn x=60 / img x=580 / ani x=1100，1x 行 y=80、2x 行 y=560， 仅 "scale" 不同，布局 rect 完全一致）：

  • test_scale_json — JSON 布局路径（"type":"button" + "luotiAni" 内嵌动画）；
  • test_scale_cabi — C ABI 编程式路径（CreateButton / 状态图 Button 3 态 / CreateAnimatedButton）；
  • sample_scale（Binding 样例）— 同一布局的 C++ 工厂断言 7 项。

三者均断言 rect 与缩放系数无关（布局矩形不随 scale 变化），并在自动模式下（auto=<秒>） 注入点击验证内嵌动画按钮的 click 事件；2x 组目测验证内容为 1x 的 2 倍、动画不双重缩放。
