10 后端差异及后端配置

10.1 选择后端

后端适用场景代价
SDL3（默认）功能最全：多窗口、多能力位、渲染器探测；游戏 / 工具通用需 3 个 DLL（SDL3 / SDL3_ttf / SDL3_image）
SFMLC++ 风格后端；四能力位齐全SFML DLL 组
raylib单 DLL 部署最简；原型 / 演示单窗口架构（无 MULTI_WINDOW）；中文需码点扩展；vsync 需创建期全局配置

10.2 编译期配置

cmake -B build -DUICORNERSTONE_BACKEND=SDL3    // SDL3 / SFML / RAYLIB
build_scripts\build.bat sdl3                   // Windows 快捷脚本

10.3 运行时配置键

key类型sdl3sfmlraylib说明
renderer-namestring（只读）✓✗✗渲染器能力探测（如 "direct3d11"）
swap-ratioint✓✗✗SDL3 SDL_SetRenderVSync（0/1/-1）
vsyncbool/int/string✓✓✓*0/1；raylib 创建期 FLAG_VSYNC_HINT，须在创建实例前用 inst=NULL 设置
// 全局默认（创建前，raylib vsync 必须走这里）
UICornerstone_SetBackendConfig(NULL, "vsync", "1");

// 实例级
UICornerstone_SetBackendConfig(g_inst, "swap-ratio", "1");
char name[64];
UICornerstone_GetBackendConfig(g_inst, "renderer-name", name, sizeof(name));

10.4 能力位

uint32_t caps = UICornerstone_GetBackendCapabilities(inst);
// UICORN_BACKEND_CAP_MULTI_WINDOW   多窗口
// UICORN_BACKEND_CAP_RENDER_TARGET  离屏渲染目标
// UICORN_BACKEND_CAP_CLIP_RECT      裁剪矩形
// UICORN_BACKEND_CAP_READBACK       像素回读
raylib 声明不含 MULTI_WINDOW：多实例下仅首个实例有真实窗口，其余为 headless（Window::isHeadless()），对其渲染会串扰到主实例窗口（内容闪动）。多窗口渲染前须条件化。

10.5 窗口配置（UIInstanceConfig）

字段默认说明
debugLabel"Instance_<id>"多实例日志区分
resourceRoot默认资源根目录（图片 / 字体 / 动画相对路径基准）
windowFlags00x00000020 可调大小；0x00002000 高 DPI；0x00020000 Utility（SDL3；SFML/raylib 忽略）
windowTitle"UICornerstone"窗口标题
windowWidth/Height1024 / 7680 → 默认

10.6 Binding Config

UICornerstone::UICornerstone::Config{}
    .WithBackend("sdl3")              // "sdl3" / "sfml" / "raylib"
    .WithBackendSearchPath("./dlls")  // 后端插件搜索路径
    .WithCoreLibraryDir("./")         // 核心 DLL 目录
    .WithResourceRoot("./assets")
    .WithWindow("My App", 800, 600);  // 标题 / 宽 / 高

10.7 高 DPI

内置 dpiScale 机制：布局坐标与渲染自动按显示器 DPI 缩放，无需业务代码适配。UIBackendCallbacks.getDpiScale 提供当前缩放值；窗口 flag 置 0x00002000 时 SDL3 按物理像素创建窗口。
