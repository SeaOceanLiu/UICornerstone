11 C++ Binding 速查表

头文件：binding/include/UICornerstone.h（含 Control.h、Event.h、UIEventFactory.h）。 C++ Binding 是 C ABI 的类型安全封装，仅依赖 C ABI 头，跨后端 DLL 动态加载。所有 UI 调用在主线程。

11.1 实例创建

struct Config {
    std::string backend            = "sdl3";   // "sdl3" | "sfml" | "raylib"
    std::string backendSearchPath;             // 后端 DLL 搜索目录（空=exe 同目录/系统搜索）
    std::string coreLibraryDir;                // 核心 DLL 所在目录（空=exe 同目录/系统搜索）
    std::string resourceRoot;                  // 资源根路径（空 → 核心默认 exe 目录/assets）
    std::string windowTitle        = "UICornerstone";
    int windowWidth  = 1024;
    int windowHeight = 768;
    // 链式：WithBackend / WithBackendSearchPath / WithCoreLibraryDir /
    //        WithResourceRoot / WithWindow(title, w, h)
};

static std::unique_ptr<UICornerstone> Create(const Config& config);
static std::unique_ptr<UICornerstone> Create(const UIBackendCallbacks* callbacks, ...);

11.5.1 TreeView item 级属性（与 C ABI 同键名，通用方法直达）

// 经 FindControl 拿到 TreeView 后，item 级属性与 C ABI 键名一致：
Control tree = ui->FindControl("controlTree");
tree.SetString("item-id", "cb1");                  // 定位目标节点
tree.SetFloat( "item-leading-gap", 10.0f);         // 容器与文本间隔
tree.SetInt(   "item-font-size", 18);
tree.SetEnum(  "item-font", "maplemono-nf-cn-regular");   // 粗体
tree.SetEnum(  "item-leading-align", "bottom-left");     // 槽位贴行底

// Label 字体样式（normal/bold/italic/underline/strikethrough）
lbl.SetEnum( PropertyNames::kFontStyle, PropertyNames::kFontStyleBold );
// 组合：分位 Bool 开关（bold + italic = 粗斜体）
lbl.SetBool( PropertyNames::kFontBold, true );
lbl.SetBool( PropertyNames::kFontItalic, true );
float gap = tree.GetFloat("item-leading-gap");

// 行前置控件容器：借出手柄 → FromHandle 包装 → GetType 判断类型 → 通用属性操作
void* lc = tree.GetPtr("item-leading-control");
Control holder = ui->FromHandle(lc);                     // 裸句柄包装为代理
if (holder.GetType() == "check-box") {
    bool checked = holder.GetBool("checked");             // 读勾选态
    holder.SetBool("checked", true);                      // 反向设置
    holder.SetCallback("check-changed", [](const Event& e){ ... });
} else if (holder.GetType() == "image") {
    /* Actor 图片控件：SetString("image", path) 等 */
}
Binding 的 Control 代理不携带控件类型信息（C ABI 句柄无类型）， GetType() 即为此提供；FromHandle() 将裸句柄（如 GetPtr("item-leading-control") 返回值）包装为代理，重复包装共享同一状态。 item 级属性（item-id / item-leading-gap / item-font-size / item-font / item-leading-control） 走 Set*/Get* 通用通道，键名与 C ABI 及 JSON 一致。
