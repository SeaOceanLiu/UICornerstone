8.4.1 tree-view item 级属性（item-id 定位模式）

先 SetString("item-id", id) 定位目标节点，随后 set/get 作用于该节点（getter 对称）：

UICornerstone_SetString(inst, tree, "item-id", "img1");     // 先定位目标节点
UICornerstone_SetFloat( inst, tree, "item-leading-gap", 10.0f);
UICornerstone_SetInt(   inst, tree, "item-font-size", 18);
UICornerstone_SetEnum(  inst, tree, "item-font", "maplemono-nf-cn-regular");
UICornerstone_SetEnum(  inst, tree, "item-leading-align", "bottom-left");   // 槽位贴行底

// Label 字体样式（normal/bold/italic/underline/strikethrough；raylib 不支持，静默无效果）
UICornerstone_SetEnum(  inst, lbl, "font-style", "bold");
// 组合：分位 Bool 开关（bold + italic = 粗斜体）
UICornerstone_SetBool(  inst, lbl, "font-bold", 1);
UICornerstone_SetBool(  inst, lbl, "font-italic", 1);
UICornerstone_GetPtr(   inst, tree, "item-leading-control", &lc);  // 借用手柄（生命周期由调用方保证）
// SetPtr 可运行时挂载容器（立即挂树）；传 NULL 解除容器并摘树：
UICornerstone_SetPtr(   inst, tree, "item-leading-control", lc);
// 相对上一级的缩进宽度（TreeView 级，既有 CABI）：
UICornerstone_SetFloat( inst, tree, "indent-width", 20.0f);

8.8 内存资源（MemoryResourceProvider）

注册内存资源后，以 provider:name 前缀在工厂 / 布局 / 属性（font-file 等）中引用，引擎不再访问磁盘；未命中注册名时回退文件系统查找。详细设计见 design/ResourceProvider_Design.md。

函数说明
int memoryProviderAdopt(provider, name, data, len, freeFn)零拷贝注册：引擎仅引用 data，覆盖/销毁时经 freeFn 释放（null → 默认 free）
int memoryProviderRegister(provider, name, data, len)拷贝注册：引擎复制字节，调用方可立即释放
int setResourceProvider(inst, role, provider)挂载到实例（角色 "resourceProviders"）；同名 provider 覆盖旧条目并先释放
UIMemoryResourceProvider* createMemoryResourceProvider(alloc, freeFn, user)创建内存 provider（alloc/freeFn 可 null → 默认 malloc/free）
/* 直连 C ABI 用法 */
UIMemoryResourceProvider* rp = createMemoryResourceProvider(NULL, NULL, NULL);
memoryProviderAdopt(rp, "cross-down", pngData, pngLen, NULL);   /* 零拷贝引用 */
setResourceProvider(inst, "resourceProviders", rp);
UICornerstone_CreateImage(inst, "provider:cross-up", 20, 70, 0, 0);
adopt 契约：调用方须保持缓冲有效直至实例销毁；C++ Binding 的 RegisterResource / AdoptResource 封装了懒创建 + 自动挂载（见 11.3）。
