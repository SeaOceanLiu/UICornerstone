6 声明式 UI 语法速查表

6.1 顶层结构

{
  "version": "1.0",
  "viewport": { "width": 1920, "height": 1080, "scale-mode": "fit" },
  "theme": { "fonts": {...}, "colors": {...} },
  "controls": [ ... ],       // 控件树根数组（必填）
  "dialogs":  [ ... ],       // 弹窗数组（可选）
  "components": { ... },     // 可复用组件模板（可选）
  "layouts": [ ... ]         // 组件实例化（可选）
}

viewport 键（可选）：声明显式基准画布与初始缩放模式，加载布局时生效 （先于控件树解析，应用于当前实例的视口缩放状态）。

键类型说明
scale-modestringoff（缺省，画布跟随窗口）/ fit（等比居中）/ stretch（拉伸铺满）
width / heightnumber基准画布尺寸（px）。缺省 = 跟随窗口（viewport）；仅记录于 off 模式，作为 fit/stretch 的适配基准

6.2 控件通用键

键类型说明
childrenarray子控件（容器类型）
colorsobject状态色：{"background":{"normal","hover","pressed","disabled"}}；键含 background/border/text/textShadow/控件特有（progressColor、titleBar 等）
eventsobject{"onClick":"handlerName"}，见 6.7
idstring全局唯一，FindControl 用
marginobject{"left","top","right","bottom"}
rectobject{"x","y","w","h"}；支持百分比字符串 "50%"
scaleobject{"x":1.0,"y":1.0}；内容按系数缩放，布局矩形不变
typestring必填。kebab 小写，全部 27 种：label / button / image / image-button / animation / edit-box / combo-box / text-area / check-box / progress-bar / slider / scroll-bar / panel / win-frame / color-picker / popup / confirm-popup / dialog / menu-bar / numeric-up-down / splitter / tree-view / context-menu（控件级 contextMenu 键，非独立控件）/ list-view / status-bar / tab-control / shape
visible / enabledbool可见 / 启用

tree-view item 增强（二期）

"items":[ {
  "id":"cb1","label":"带勾选框的行",
  "leadingControl":{ "type":"check-box", "checkState":"checked" },
  "leadingGap":10
}, {
  "id":"img1","label":"带图标的行",
  "leadingControl":{ "type":"image", "image":"assets/images/cross_down.png" },
  "font":"harmonyos-sans-sc-bold", "size":16
} ]
  • leadingControl：行前置控件容器（控件 JSON，复用 type + 控件属性， 支持 check-box / image 等）。rect 由 TreeView 自适应（高 = 行内文字高度，宽按原始宽高比等比）， 文字缩进 = 无容器时文本缩进，文字被容器让位右移。
  • leadingGap：控件容器与文本之间的间隔（局部 px，默认 6）。
  • font：逐 Item 字体枚举（如 harmonyos-sans-sc-bold 粗体）， size：逐 Item 字号（0 = 继承 TreeView 级）。
  • alignment：槽位对齐（复用 Label 的 alignment 键与 9 宫格字符串， 如 "bottom-left"；默认 "mid-left" 居中；水平分量忽略，槽位贴文本起点）。

item 级属性的编程式操作（item-id 定位模式）见 8.4.1。

6.5 布局引擎

h-flow / v-flow

"layout": { "type": "h-flow", "gap": 4,
             "padding": { "left": 4, "top": 4, "right": 4, "bottom": 4 } }
// 子控件：{ ..., "flowWeight": 1 }  弹性分配；0/缺省=固定

anchor

"layout": { "type": "anchor" }
// 子控件：
{ ..., "anchor": "top-right",
  "anchorOffset": { "left": 10, "top": 10, "right": 0, "bottom": 0 } }
// 锚点值（小写连字符）：
//   top-left top-center top-right / mid-left center mid-right
//   bottom-left bottom-center bottom-right
//   top-stretch bottom-stretch left-stretch right-stretch fill
// 含义见下方「anchor 取值含义」表

anchor 取值含义

取值（小写连字符）含义
top-left / top-center / top-right靠顶部：左/中/右对齐（top-left/top-right 用 offset.left+top / offset.right+top 定距）
mid-left / center / mid-right垂直居中：左/中/右对齐（center 居中后 offset.left+top 额外位移）
bottom-left / bottom-center / bottom-right靠底部：左/中/右对齐（offset.bottom 定底距）
top-stretch顶部拉伸：宽度填满容器（扣 offset.left+right），顶部固定
bottom-stretch底部拉伸：宽度填满容器，底部固定
left-stretch左侧拉伸：高度填满容器（扣 offset.top+bottom），左侧固定
right-stretch右侧拉伸：高度填满容器，右侧固定
fill填满容器内边距区域（宽高均填满，扣四边 offset 与布局 padding）

grid

"layout": { "type": "grid",
             "columns": ["1fr", "2fr", "100px"],
             "rows": ["30px", "1fr", "auto"] }
// 子控件：{ ..., "grid": { "row":0, "col":1, "rowSpan":1, "colSpan":1 } }
// 尺寸：Fixed "100px" / Flex "1fr" / Auto "auto"
