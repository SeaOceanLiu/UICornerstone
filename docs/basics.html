3 从基础入门

UICornerstone 的一切都是控件（Control）：按钮、标签、输入框……你创建它们，用属性（Property）读写它们的表现（SetString/GetInt 等），用事件回调响应交互（点击、文本变化），由核心引擎统一完成布局、样式渲染与对象生命周期管理——你不需要关心任何平台细节。

本库提供 C ABI（core/ 与 include/）与 C++ Binding（binding/）两层接口：C++ Binding 是推荐的上手方式，把 C ABI 包装为现代 C++ 接口并纯动态加载核心 DLL，无静态链接耦合；主循环支持 Hosted（UI 托管）与 Embedded（嵌入你自己的游戏/工具循环）两种模式；除了代码编程，还可用 JSON 编写声明式 UI。

本章你能学到什么

  • 3.1 使用 C++ Binding 搭建：CMake 集成、核心头文件，写一个最小可运行的应用；
  • 3.2 创建你的第 1 个 UICornerstone 应用：完整例子——控件工厂、属性读写、回调，以及 Hosted/Embedded 两种主循环；
  • 3.3 属性系统：Set/Get 背后的统一属性模型，理解"属性驱动"的精髓；
  • 3.4 声明式 UI：用 JSON 描述界面，少写代码（推荐）；
  • 3.5 事件：回调注册与 Event 具名访问器；
  • 3.6 焦点系统：Tab 焦点导航与焦点样式；
  • 3.7 洛蒂动画：加载 Lottie 动画并绑定到控件。

完成本章后，你将能够独立搭建环境、创建窗口与控件、响应交互，并选择适合自己项目的主循环模式——随后进入 第 4 章 深入控件 逐个掌握全部控件。
