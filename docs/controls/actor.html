4.1 Actor（图片控件）

Actor 是纯显示图片的控件（C ABI 中即 Image 控件）。它不参与事件命中与遮挡检测（isContainsPoint 恒为 false），常作为 Button 的四态外观、背景图或纯装饰。继承链：Actor → Material → ControlImpl → Control。

4.1.1 控件的创建

// C++ 构造（4 个重载）
Actor(Control* parent, float xScale = 1.0f, float yScale = 1.0f);
Actor(Control* parent, bool matchParentRect, float xScale = 1.0f, float yScale = 1.0f);
Actor(Control* parent, fs::path filePath, bool matchParentRect = false, float xScale = 1.0f, float yScale = 1.0f);
Actor(Control* parent, string resourceId, bool matchParentRect = false, float xScale = 1.0f, float yScale = 1.0f);

// Builder
ActorBuilder(parent).loadFromFile("assets/img/icon.png").setMatchParentRect(true).build();

// C ABI（w/h 传 0 按纹理自然尺寸）
UIControlHandle img = UICornerstone_CreateImage(g_inst, "assets/img/icon.png", 20, 20, 128, 128, 1.0f, 1.0f);
JSON 布局中 Actor 两种用法：独立 image 节点（见 4.1.4），或作为 Button 的 actors 子键（见 4.1.5）。

4.1.3 控件的回调

无（纯显示控件，不产生任何事件）。

4.1.4 JSON 语法（独立 image 节点）

// 独立图片：image 键（文件路径，相对 resourceRoot）或 imageResource / providerName（内存资源 ID）
{ "type": "image", "id": "hero", "rect": { "x": 60, "y": 60, "w": 128, "h": 128 },
  "image": "assets/images/cross_up.png", "scale-type": "fit-center" }

// 支持键：image / imageResource / providerName / matchParentRect / scaleType /
//          rect / scale / visible / enabled / margin / colors / styles / events / id
// scaleType：stretch（默认）/ fit-center / center-crop / none / tile

4.1.5 JSON 语法（Button 的 actors）

{
  "type": "button", "id": "imageBtn",
  "rect": { "x": 60, "y": 300, "w": 48, "h": 48 },
  "actors": {
    "normal":  "assets/images/cross_up.png",
    "hover":   "assets/images/cross_over.png",
    "pressed": "assets/images/cross_down.png"
  }
}

4.1.6 C++ Binding 样例

// Binding：CreateImage（对应 C ABI CreateImage）
Control img = ui->CreateImage("assets/hero.png", 20, 80, 128, 128);
img.SetEnum(PropertyNames::kScaleType, "fit-center");
img.SetInt(PropertyNames::kAlpha, 128);
img.SetBool(PropertyNames::kMatchParentRect, false);

// C++ 核心库：作为 Button 三态外观
auto normal = ActorBuilder(nullptr).loadFromFile("assets/img/icon.png").setMatchParentRect(true).build();
auto hover  = ActorBuilder(nullptr).loadFromFile("assets/img/icon_hover.png").setMatchParentRect(true).build();
auto btn = ButtonBuilder(nullptr, SRect(380, 50, 120, 50))
    .setNormalStateActor(normal).setHoverStateActor(hover)
    .build();
BENCH->addControl(btn);

4.1.7 C ABI 调用样例

// C ABI 中 Actor 即 Image 控件（w/h 传 0 按纹理自然尺寸）
UIControlHandle img = UICornerstone_CreateImage(g_inst, "assets/img/icon.png", 20, 20, 0, 0, 1.0f, 1.0f);

// 属性：键名见「控件的属性」表
UICornerstone_SetEnum(g_inst, img, "scale-type", "fit-center");
UICornerstone_SetInt(g_inst, img, "alpha", 128);
UICornerstone_SetBool(g_inst, img, "match-parent-rect", 0);

// Actor 纯显示、无事件；经 SetRect / DestroyControl 通用操作
UICornerstone_SetRect(g_inst, img, 60, 20, 128, 128);
