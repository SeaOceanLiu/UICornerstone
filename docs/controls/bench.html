4.2 Bench（测试台 / 根控件）

Bench 是每个 UIContext 实例的控件树根节点：它承载整个界面的事件循环入口、焦点作用域切换，并作为所有顶层控件的父容器。继承链：Bench → Panel → ControlImpl → Control，并混入 TopControl（事件泵）。

4.2.1 控件的创建

// 唯一构造：由 UIContext 内部创建，用户不直接 new
explicit Bench(UIContext* ctx);
// 访问方式
BENCH->addControl(btn);            // 核心库：宏获取当前 Bench 智能指针
BENCH->setOnInitial(callback);     // 资源加载完成回调
Bench 无 C ABI 创建函数、无 JSON type——它是布局解析器的挂载目标，不作为可声明控件存在。

4.2.2 控件的属性

4.2.4 JSON 语法

无（Bench 不是 JSON 控件类型）。所有布局文件的 controls 数组都解析挂载到 Bench 之下。

4.2.5 C ABI 调用样例

Bench 是 UIContext 内部的控件树根，无 C ABI 工厂、无句柄，因此 C ABI 用户无需（也无法）直接操作它：

// 布局 JSON 的顶层控件自动挂到 Bench（布局解析器的挂载目标）
static void onBtnClick(UIControlHandle ctl, const UIEventData* ev, void* ud) { }
if (UICornerstone_LoadLayout(g_inst, layoutJson)) {
    // 查找带 id 的控件后统一走属性系统
    UIControlHandle btn = UICornerstone_FindControl(g_inst, "submitBtn");
    UICornerstone_SetCallback(g_inst, btn, "click", onBtnClick, NULL);
}
Bench 的 "initial" 事件（资源加载完成）由引擎内部触发，C ABI 层无需绑定。
