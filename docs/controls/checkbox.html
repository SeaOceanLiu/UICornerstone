4.4 CheckBox（复选框）

CheckBox 支持三态（未勾选 / 勾选 / 半选）、三种符号样式与两种文字排布，内部组合一个 Label 作标题。继承链：CheckBox → ControlImpl → Control。

缩放联动：标题文本为内部 Label（树成员），置于缩放画布（fit / stretch，见 5.6 视口画布缩放）时字号随复合缩放系数重建。

4.4.1 控件的创建

// C++
CheckBox(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
CheckBoxBuilder(parent, SRect(50, 50, 200, 30)).setCaptionText("Accept").setOnCheckChanged(cb).build();

// C ABI
UIControlHandle cb = UICornerstone_CreateCheckBox(g_inst, "Accept", 50, 50, 100, 30, 1.0f, 1.0f);

// JSON
{ "type": "check-box", "id": "agreeCheck", "rect": { "x": 240, "y": 432, "w": 180, "h": 30 },
  "caption": "I agree", "check-state": "unchecked", "style": "classic",
  "events": { "onCheckChanged": "onAgreeChanged" } }

4.4.3 控件的回调

内部标题（caption）各态色经 caption-label 句柄设置（GetPtr("caption-label") → 直控 Label）；各态随 CheckBox 状态（hover/pressed/disabled）自动生效。

CheckBox 不派发 click / kEventClick——点击（含键盘触发）统一由 check-changed 表达状态变化。需要点击逻辑时请使用 check-changed。

事件名事件常量触发时机参数
check-changedkEventCheckChanged鼠标左键抬起或焦点态按 Space 触发状态循环后Int（intVal = 新 CheckState 枚举值 0/1/2）

4.4.4 JSON 语法

{
  "type": "check-box", "id": "agreeCheck",
  "rect": { "x": 240, "y": 432, "w": 180, "h": 30 },
  "caption": "I agree", "font-size": 14,
  "check-state": "unchecked",
  "style": "classic", "layout": "text-right",
  "events": { "onCheckChanged": "onAgreeChanged" }
}

4.4.5 C++ Binding 样例

auto cb = ui->CreateCheckBox("Accept Terms", 50, 50, 100, 30);
cb.SetEnum(PropertyNames::kCheckState, "checked");   // 或 cb.SetBool(PropertyNames::kChecked, true)
cb.SetEnum(PropertyNames::kCheckBoxStyle, "classic");
cb.SetBool(PropertyNames::kTriState, false);         // 关闭三态
cb.SetCallback(PropertyNames::kEventCheckChanged, [](const Event& e) {
    int st = e.GetCheckState();    // 0=unchecked 1=checked 2=indeterminate
    printf("state=%d\n", st);
});

4.4.6 C ABI 调用样例

UIControlHandle cb = UICornerstone_CreateCheckBox(g_inst, "Accept", 20, 20, 24, 24, 1.0f, 1.0f);

UICornerstone_SetString(g_inst, cb, "caption", "同意协议");
UICornerstone_SetBool(g_inst, cb, "tri-state", 1);      // 三态
UICornerstone_SetEnum(g_inst, cb, "style", "cross");    // classic / cross / circle

static void onCheckChanged(UIControlHandle ctl, const UIEventData* ev, void* ud) {
    /* ev->data.intVal 为当前 check-state */
}
UICornerstone_SetCallback(g_inst, cb, "check-changed", onCheckChanged, NULL);
