4.7 ContextMenu（右键菜单）

ContextMenu 右键上下文菜单：Popup 浮层 + MenuPanel（子菜单/分隔线/图标/快捷键全支持），Esc / 外部点击 / 点项自动关闭。继承链：ContextMenu → Popup → Panel。设计文档见 design/ContextMenu_Design.md。

4.7.1 控件的创建

// C++
auto menu = ContextMenuBuilder(1, 1).addItem(u8"复制", cb).addSeparator()
               .addItem(u8"删除", cb2).build();
menu->show(140, 160);

// C ABI
UIControlHandle m = UICornerstone_CreateContextMenu(g_inst, 0, 0, 10, 10, 1, 1);
UICornerstone_ContextMenuAddItem(g_inst, m, u8"复制", nullptr);
UICornerstone_ContextMenuShow(g_inst, m, 140, 160);

// JSON（控件级绑定：右键该控件弹出）
{ "type": "label", "rect": [10, 10, 120, 24],
  "context-menu": { "items": [ {"caption": "Open", "shortcut": "Ctrl+O"} ] } }

4.7.2 控件的属性

ContextMenu 为行为型浮层，无独立属性系统键；菜单项内容/样式由 MenuPanel/MenuItem 体系承载，经 JSON contextMenu.items[] 声明（caption / shortcut / type / icon，见 4.7.4）。

4.7.3 控件的回调 / 事件

事件名事件常量触发时机参数
onClickkEventKeyClick点击菜单项（回调后自动关闭）无
菜单视觉由 MenuPanel 全权负责（圆角边框+阴影）；弹出位置自动视口钳制；点击子菜单区域不误判为外部点击。

4.7.4 JSON 语法

{
  "type": "label", "id": "lbl", "rect": { "x": 10, "y": 10, "w": 120, "h": 24 },
  "context-menu": {
    "items": [
      { "caption": "Open", "shortcut": "Ctrl+O" },
      { "type": "separator" },
      { "caption": "Delete" }
    ]
  }
}
JSON 键类型说明
items[].captionString菜单项文本
items[].shortcutString快捷键列
items[].typeEnum菜单项类型（separator ↔ kMenuTypeSeparator 等，见 7.3）
items[].icon资源引用项图标（常量同 kItemIcon）

4.7.5 C++ Binding 样例

auto menu = ui->CreateContextMenu(0, 0, 10, 10);
menu->AddItem(u8"复制", [](shared_ptr it) { /* 用户回调 */ });
menu->AddSeparator();
lbl->SetPtr(PropertyNames::kPropContextMenu, menu->GetThis());  // 右键绑定

4.7.6 C ABI 调用样例

UIControlHandle m = UICornerstone_CreateContextMenu(g_inst, 0, 0, 10, 10, 1.0f, 1.0f);
UICornerstone_ContextMenuAddItem(g_inst, m, u8"复制", "Ctrl+C");
UICornerstone_ContextMenuAddSeparator(g_inst, m);
UICornerstone_ContextMenuShow(g_inst, m, 140, 160);
UICornerstone_SetPtr(g_inst, lbl, "context-menu", m);   // 右键绑定
4.7.7 控件的方法（核心引擎内部 API，点击展开）
本节为核心引擎 C++ 类（include/ 头文件）的公开方法，仅源码级集成（直接使用核心类）可调用。只使用 C ABI / C++ Binding 的用户请按「控件的属性」键名（Set*/Get*）与「控件的回调」事件名（SetCallback）等价操作。
方法参数
show(float x, float y)在指定位置弹出（bench 坐标，自动视口钳制）
close(DialogResult result = Cancelled)关闭菜单（面板 hide + Popup::close）
addItem(shared_ptr<MenuItem>) / addItem(caption, onClick)添加菜单项（包装用户回调：回调后自动关闭）
addSeparator()添加分隔线
setContextMenu(menu) / getContextMenu()控件级右键绑定（ControlBase 侧）
getMenuPanel()内容面板（MenuPanel）访问
isContainsPoint(x, y)（override）命中：自身或 MenuPanel（含子菜单）区域
setXxxProperty / getXxxProperty（override）属性分发
