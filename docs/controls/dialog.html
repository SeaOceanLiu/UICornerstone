4.8 Dialog / Popup（弹窗族）

三层弹窗族：Popup（无按钮）→ ConfirmPopup（+确定按钮，Enter 确认）→ Dialog（+取消按钮，ESC/外部点击走取消）。三者均为非模态（事件驱动，不阻塞主循环）。继承链：Dialog → ConfirmPopup → Popup → Panel。

4.8.1 控件的创建

// C++
Dialog(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
DialogBuilder(parent, rect).setCentered().setOnConfirm(cb).setOnCancel(cb2).build();

// C ABI（创建即 open()，并加入 popupPool 保持生命期）
UIControlHandle dlg = UICornerstone_CreateDialog(g_inst, "OK", "Cancel", 0, 0, 296, 440, 1.0f, 1.0f);

// C++ Binding
auto dialog = vp->CreateDialog("OK", "", 0, 0, 280, 120);   // 居中弹窗
dialog.AddChild(vp->CreateLabel("Are you sure?", 14.0f, 20, 30, 240, 60));

4.8.4 JSON 语法（顶层 dialogs 数组）

{
  "type": "dialog", "id": "colorDlg",
  "centered": true,
  "rect": { "x": 0, "y": 0, "w": 296, "h": 440 },
  "colors": { "background": { "normal": "#E0E0E0FF" } },
  "confirm-button": { "text": "OK" },
  "cancel-button": { "text": "Cancel" },
  "events": {
    "onConfirm": "onColorConfirmed",
    "onCancel": "onColorCancelled",
    "onClose": "onColorClose"
  },
  "children": [
    { "type": "edit-box", "id": "hexInput",
      "rect": { "x": 72, "y": 168, "w": 130, "h": 28 }, "text": "#FF6600FF" }
  ]
}

通用子键：button-height / button-gap / padding；confirm-button / cancel-button 支持 text / rect / visible。默认隐藏；C ABI 侧 SetBool(inst, dlg, "visible", 1) 打开。

4.8.5 C++ Binding 样例

auto dialog = vp->CreateDialog("OK", "", 0, 0, 280, 120);   // 居中
auto label  = vp->CreateLabel("Delete this file?", 14.0f, 20, 30, 240, 60);
dialog.AddChild(label);
dialog.SetCallback(PropertyNames::kEventConfirm, [](const Event& e) {
    printf("confirmed, result=%d\n", e.GetCloseResult());
});
dialog.SetCallback(PropertyNames::kEventCancel, [](const Event&) {
    printf("cancelled\n");
});
dialog.SetBool(PropertyNames::kVisible, true);   // 打开弹窗
数据取回：内容控件经 getContent() + dynamic_pointer_cast 读取。一次只弹一个弹窗，嵌套需自行管理。

4.8.6 C ABI 调用样例

UIControlHandle dlg = UICornerstone_CreateDialog(g_inst, "确定", "取消", 200, 150, 320, 180, 1.0f, 1.0f);

UICornerstone_SetString(g_inst, dlg, "confirm-text", "好的");
UICornerstone_SetBool(g_inst, dlg, "close-on-esc", 1);

static void onConfirm(UIControlHandle ctl, const UIEventData* ev, void* ud) {
    /* 用户点击确定 */
}
static void onCancel(UIControlHandle ctl, const UIEventData* ev, void* ud) {
    /* 用户取消 */
}
UICornerstone_SetCallback(g_inst, dlg, "confirm", onConfirm, NULL);
UICornerstone_SetCallback(g_inst, dlg, "cancel", onCancel, NULL);
