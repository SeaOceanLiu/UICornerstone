4.9 EditBox（单行输入框）

EditBox 是单行文本输入控件：支持光标、选区、剪贴板（Ctrl+C/X/V）、密码模式、占位符与焦点管理。多行输入请用 TextArea（4.9）。继承链：EditBox → ControlImpl → Control。

缩放联动：置于缩放画布（fit / stretch，见 5.6 视口画布缩放）时，字号随复合缩放系数重建；不可见时延后重建，变为可见的当帧自动补重建。

4.9.1 控件的创建

// C++
EditBox(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
EditBoxBuilder(parent, SRect(50, 50, 300, 40)).setPlaceholder("Type here...").build();

// C ABI
UIControlHandle edit = UICornerstone_CreateEditBox(g_inst, 20, 193, 240, 95, 1.0f, 1.0f);

// JSON
{ "type": "edit-box", "id": "nameEdit",
  "rect": { "x": 110, "y": 20, "w": 250, "h": 30 },
  "placeholder": "Please input your name",
  "font": { "size": 16 },
  "colors": { "background": { "normal": "#404040FF" }, "border": { "normal": "#606060FF" } } }

4.9.4 JSON 语法

{
  "type": "edit-box", "id": "nameEdit",
  "rect": { "x": 110, "y": 20, "w": 250, "h": 30 },
  "placeholder": "Please input your name",
  "text": "Default text",
  "font": { "size": 16 },
  "colors": { "background": { "normal": "#404040FF" }, "border": { "normal": "#606060FF" } },
  "events": { "onTextChanged": "onNameChanged", "onEnter": "onNameEnter" }
}

4.9.5 C++ Binding 样例

auto edit = ui->CreateEditBox(20, 193, 240, 95);
edit.SetString(PropertyNames::kPlaceholder, "Type here...");
edit.SetBool(PropertyNames::kPasswordMode, false);
edit.SetCallback(PropertyNames::kEventTextChanged, [](const Event& e) {
    printf("text: %s\n", e.GetTextChanged().c_str());
});
edit.SetCallback(PropertyNames::kEventEnter, [](const Event&) {
    printf("Enter pressed\n");
});

4.9.6 C ABI 调用样例

UIControlHandle box = UICornerstone_CreateEditBox(g_inst, 20, 20, 200, 30, 1.0f, 1.0f);

UICornerstone_SetString(g_inst, box, "text", "hello");
UICornerstone_SetString(g_inst, box, "placeholder", "请输入…");
UICornerstone_SetBool(g_inst, box, "password-mode", 1);
UICornerstone_SetBool(g_inst, box, "read-only", 1);   // P0-83：只读（禁编辑，可选复制）

static void onTextChanged(UIControlHandle ctl, const UIEventData* ev, void* ud) {
    /* ev->data.strVal 为当前文本 */
}
UICornerstone_SetCallback(g_inst, box, "text-changed", onTextChanged, NULL);
