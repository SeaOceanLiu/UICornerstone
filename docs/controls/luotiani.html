4.13 LuotiAni（关键帧动画控件）

LuotiAni 是播放关键帧动画的控件：JSON 描述动画（见 3.7 洛蒂动画），运行时烘焙为帧贴图，播放按毫秒查表。多实例共享烘焙帧数据。继承链：LuotiAni → Material → ControlImpl → Control。

4.13.1 控件的创建

// C++（构造不加载）
LuotiAni(Control* parent, float xScale = 1.0f, float yScale = 1.0f);
LuotiAniBuilder(BENCH.get())
    .loadAniDesc("animations/rotateBtn/rotateBtn.jsonc")
    .setRect(SRect(20, 20, 256, 256))
    .prepare().setAutoStart().build();

// C ABI（w/h 传 0 时 prepare 回退到 JSON overview.view 画布尺寸；失败返回 NULL）
UIControlHandle ani = UICornerstone_CreateAnimation(g_inst, "tA1.jsonc", 20, 20, 256, 256, 1.0f, 1.0f);

// C++ Binding
Control ani = ui->CreateAnimation("animations/breath/breath.jsonc", 20, 20, 0, 0);

4.13.2 控件的属性

属性属性常量类型默认值说明
animationkAnimationString—JSONC 路径（只写不读）；加载+prepare，播放中则从第 0 帧重播；失败返回 0
framekFrameInt0跳帧（setFrame）；未 prepare 拒绝
loopkLoopBoolJSON 中值setLoop / getLoop
playingkPlayingBool0命令式：置 1 = play()（帧复位重播），置 0 = pause()；未 prepare 置 1 记录请求并返回 1，prepare 完成后自动播放

枚举值与常量对应（如 classic ↔ kStyleClassic）见 7.3 枚举值速查。

4.13.3 控件的回调

事件名事件常量触发时机参数
AnimationEnded（Custom 事件）kEventAnimationEnded（"animation-ended"）非循环播放到最后一帧后intVal = 动画 id（m_id，-1 为未指定）

4.13.4 JSON 动画文件语法

真实键名是 layer / keyFrames / frame / operation（不存在 track/target/property 这类键）：

{
  "overview": {
    "version": "1.0", "name": "breath",
    "view": { "width": 200, "height": 200 },
    "frameRate": 60, "totalFrames": 40, "loop": true
  },
  "layers": [
    { "name": "glow", "type": "image", "src": "images/glow.png",
      "opacity": 80, "blendMode": "additive",
      "keyFrames": [
        { "frame": 0,  "operation": [ { "type": "scale", "sx": 0.8, "sy": 0.8 } ] },
        { "frame": 20, "operation": [ { "type": "scale", "sx": 1.2, "sy": 1.2, "easing": "ease-in-out" } ] },
        { "frame": 40, "operation": [ { "type": "scale", "sx": 0.8, "sy": 0.8 } ] }
      ] }
  ]
}
字段参数
easinglinear（默认）/ ease-in / ease-out / ease-in-out / quad / sine / cubic / cubic-bezier(x1,y1,x2,y2)
keyFrames[].frame帧号，第 0 帧关键帧必须存在
layer.blendModenormal / additive / additivePremultiplied / modulate / blend / blendPremultiplied / multiply，未知回退 normal
layer.typeimage 完整支持；shape/text 解析支持但烘焙跳过
layer.width/height显式拉伸，缺省用贴图原始尺寸
operation.typetranslate（tx,ty 增量累加）/ scale（sx,sy 累乘）/ rotate（angle 累加, cx,cy 旋转中心）/ opacity（0~100 百分比覆盖）/ visible
path仅 translate 的段内轨迹：bezier{c1x,c1y,c2x,c2y} / parabola{vx,vy} / catmull-rom{points[{x,y}]}

4.13.5 C++ Binding / C ABI 样例

// C ABI
UIControlHandle h = UICornerstone_CreateAnimation(g_uiInstance, "tA1.jsonc", 20, 20, 256, 256, 1.0f, 1.0f);
UICornerstone_SetBool(g_uiInstance, h, "playing", 1);
UICornerstone_SetBool(g_uiInstance, h, "loop", 1);
UICornerstone_SetInt (g_uiInstance, h, "frame", 10);   // 跳帧

// C++ Binding
Control ani = ui->CreateAnimation("animations/breath/breath.jsonc", 20, 20, 0, 0);
ani.SetBool(PropertyNames::kPlaying, true);
ani.SetBool(PropertyNames::kLoop, true);

// Button 载体（JSON）——luotiAni 键：挂树后自动延迟 prepare；"playing": true 则 prepare 后自动播放，缺省不播（SetBool(PropertyNames::kPlaying)=1 启动）
{ "type": "button", "id": "animatedBtn",
  "rect": { "x": 40, "y": 40, "w": 120, "h": 40 },
  "caption": "Rotate",
  "luotiAni": "assets/animations/rotateBtn/rotateBtn.jsonc" }

// Button 载体（编程式）——动画按钮工厂：scale 作用于按钮本身，内嵌动画恒 1.0（防双重缩放）
UIControlHandle h2 = UICornerstone_CreateAnimatedButton(g_uiInstance, "tA1.jsonc", 40, 100, 120, 40, 2.0f, 2.0f);
Control aniBtn = ui->CreateAnimatedButton("animations/breath/breath.jsonc", 40, 150, 120, 40);
4.13.6 控件的方法（核心引擎内部 API，点击展开）
本节为核心引擎 C++ 类（include/ 头文件）的公开方法，仅源码级集成（直接使用核心类）可调用。只使用 C ABI / C++ Binding 的用户请按「控件的属性」键名（Set*/Get*）与「控件的回调」事件名（SetCallback）等价操作。
方法参数
draw(x, y, alpha) / draw(frameNo, x, y, alpha)绘制当前帧 / 指定帧
getFrameActor(uint32_t)帧 Actor 调试 / 断言访问
getFrameDuration() / getTotalFrames() / getCurrentFrame()帧时长(ms) / 总帧数 / 当前帧
getFrameOpData(layer, frame) / getFrameCanvas(frame)调试：层/帧插值结果 / 烘焙画布
isLoop() / setLoop(bool)循环开关
isPlaying() / isPrepared() / isLoaded()状态查询
loadAniDesc(fs::path) / loadAniDesc(string)加载 JSON 描述（相对路径拼资源根；失败 throw）
loadFromFile(fs::path) / loadFromResource(string)加载（委托 loadAniDesc）
parseJsonDesc()解析 JSON（换动画时重置状态）
pause() / resume()暂停 / 从暂停处继续（resume 未 prepare 抛异常）
play()帧复位到 0 重播（未 prepare 抛异常）
prepare(uint32_t startFrame = 0)烘焙全部帧贴图（未加载抛异常）
setFrame(uint32_t)跳帧（仅已 prepare 且帧号合法生效，同时复位时间戳防跳变）
setFrameFilter(bool)帧位图采样过滤：true=双线性（平滑，画布缩放后推荐）、false=最近邻（像素风）；经 RenderDevice::setTextureFilter 落三后端
setRect(SRect)同步所有帧 Actor 矩形
update()按毫秒推进帧（绝对墙钟，与帧率无关）；非循环结束复位到帧 0 并触发 AnimationEnded 事件
