4.15 NumericUpDown（数值微调框）

NumericUpDown 是数值输入控件：编辑框 + 上下箭头按钮，支持范围钳位、步长/页步长、小数精度、只读模式与长按自动步进。继承链：NumericUpDown → EditBox → ControlImpl → Control。

缩放联动：编辑文本继承 EditBox 字体链路，置于缩放画布（fit / stretch，见 5.6 视口画布缩放）时字号随复合缩放系数重建。

4.15.1 控件的创建

// C++
NumericUpDown(Control* parent, const SRect& rect, float xScale = 1.0f, float yScale = 1.0f);
NumericUpDownBuilder(BENCH.get(), {220, 90, 150, 24})
    .setValue(0.6).setRange(0.0, 1.0).setStep(0.2).setDecimals(2).build();

// C ABI
UIControlHandle nud = UICornerstone_CreateNumericUpDown(g_inst, 20, 78, 180, 32, 1.0f, 1.0f);

// JSON
{ "id": "nudInteger", "type": "numeric-up-down",
  "rect": { "x": 20, "y": 78, "w": 180, "h": 32 },
  "value": 50, "range": { "min": 0, "max": 100 },
  "step": 1, "page-step": 10, "decimals": 0,
  "placeholder": "0", "read-only": false, "button-width": 28,
  "events": { "onValueChanged": "onPosXChanged" } }

4.15.5 C++ Binding 样例

Control nud = ui->CreateNumericUpDown(20, 78, 180, 32);
nud.SetFloat(PropertyNames::kValue, 50.0f);
nud.SetFloat(PropertyNames::kRangeMax, 100.0f);
nud.SetFloat(PropertyNames::kStep, 1.0f);
nud.SetCallback(PropertyNames::kEventValueChanged, [](const Event& e) {
    printf("value = %.2f\n", e.GetValueChangedDouble());   // 双精度负载
});

// 核心库
auto nud2b = NumericUpDownBuilder(BENCH.get(), {220, 90, 150, 24})
    .setValue(0.6).setRange(0.0, 1.0).setStep(0.2).setDecimals(2)
    .setOnValueChanged([](shared_ptr, double v) {
        printf("[nud2b] 当前值 = %.2f\n", v);
    })
    .build();
BENCH->addControl(nud2b);

4.15.6 C ABI 调用样例

UIControlHandle nud = UICornerstone_CreateNumericUpDown(g_inst, 20, 20, 120, 26, 1.0f, 1.0f);

UICornerstone_SetFloat(g_inst, nud, "value", 50);
UICornerstone_SetFloat(g_inst, nud, "range-min", 0);
UICornerstone_SetFloat(g_inst, nud, "range-max", 100);
UICornerstone_SetFloat(g_inst, nud, "step", 5);

static void onValueChanged(UIControlHandle ctl, const UIEventData* ev, void* ud) {
    /* ev->data.doubleVal / floatVal 为新值 */
}
UICornerstone_SetCallback(g_inst, nud, "value-changed", onValueChanged, NULL);
