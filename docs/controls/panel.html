4.16 Panel（容器）

Panel 是最基本的容器控件：管理子控件、分发事件、绘制背景/边框，并可挂载布局引擎（流式 / 锚点 / 网格）。所有容器（Bench、WinFrame、Dialog 等）都继承自它。继承链：Panel → ControlImpl → Control。

4.16.1 控件的创建

// C++
Panel(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
PanelBuilder(parent, SRect(50, 112, 400, 200)).setBGColor(...).addControl(child).build();

// C ABI
UIControlHandle panel = UICornerstone_CreatePanel(g_inst, 50, 112, 400, 200, 1.0f, 1.0f);

// JSON
{ "type": "panel", "id": "formPanel",
  "rect": { "x": 50, "y": 112, "w": 400, "h": 200 },
  "layout": { "type": "h-flow", "gap": 4, "padding": { "left": 4, "top": 4, "right": 4, "bottom": 4 } },
  "children": [ { "type": "button", "id": "submitBtn", "rect": { "x": 280, "y": 140, "w": 100, "h": 35 },
                  "caption": "Submit", "events": { "onClick": "onSubmitClick" } } ] }

4.16.3 控件的回调

无专有回调（子控件的事件由其自身处理）。

4.16.4 JSON 语法（含布局引擎）

// h-flow / v-flow（子控件用 flow-weight 弹性分配）
{ "type": "panel", "id": "formPanel",
  "rect": { "x": 50, "y": 112, "w": 400, "h": 200 },
  "colors": { "border": { "normal": "#808080FF" } },
  "layout": { "type": "h-flow", "gap": 4,
              "padding": { "left": 4, "top": 4, "right": 4, "bottom": 4 } },
  "children": [
    { "type": "edit-box", "id": "nameEdit", "flow-weight": 1, "rect": { "w": 0, "h": 30 } },
    { "type": "button", "id": "submitBtn", "rect": { "w": 100, "h": 35 } }
  ] }

// anchor（子控件 anchor + anchorOffset）
"layout": { "type": "anchor" },
"children": [ { "type": "button", "id": "okBtn", "rect": { "w": 100, "h": 32 },
                "anchor": "top-right",
                "anchorOffset": { "left": 10, "top": 10, "right": 0, "bottom": 0 } } ]

// grid（columns/rows 支持 100px / 1fr / auto）
"layout": { "type": "grid", "columns": ["1fr", "2fr", "100px"], "rows": ["30px", "1fr", "auto"] },
"children": [ { "type": "button", "id": "cellBtn",
                "grid": { "row": 0, "col": 1, "rowSpan": 1, "colSpan": 1 } } ]

4.16.5 C++ Binding 样例

auto panel = ui->CreatePanel(50, 112, 400, 200);
auto btn   = ui->CreateButton("Submit", 280, 140, 100, 35);
panel.AddChild(btn);                          // 挂载（返回 child；自动摘旧父，跨容器 reparent 无双挂载）
ui->RemoveChild(panel, btn);                  // 摘除但不销毁（实例级保活，可再 AddChild 回挂）
panel.AddChild(btn);                          // 复挂（复位示例）
btn.SetBool(PropertyNames::kEnabled, false);  // 统一属性系统
btn.SetCallback(PropertyNames::kEventClick, [](const Event&) { /* ... */ });
运行时挂载：AddChild 的父须为 Panel（WinFrame 严格挂 ClientPanel，传 ui->FromHandle(wf.GetPtr(PropertyNames::kClientPanel)) 代理）；子控件 rect 为父局部坐标，跨容器挂载不自动换算全局位置；真销毁用 Control::Destroy()（RemoveChild 只摘除、保活）。
布局引擎（flow/anchor/grid）的完整 JSON 语法见 6 声明式 UI 语法速查表。

4.16.6 C ABI 调用样例

// 容器：创建后经 AddChildControl 挂子控件
UIControlHandle panel = UICornerstone_CreatePanel(g_inst, 20, 20, 400, 300, 1.0f, 1.0f);
UIControlHandle btn = UICornerstone_CreateButton(g_inst, "OK", 10, 10, 100, 32, 1.0f, 1.0f);

UICornerstone_AddChildControl(g_inst, panel, btn);   // 挂树：任意旧父自动摘除；非 Panel/自身/祖先环静默忽略
UICornerstone_RemoveChild(g_inst, panel, btn);       // 摘除不销毁（保活，可再挂）；销毁用 DestroyControl
UICornerstone_AddChildControl(g_inst, panel, btn);   // 复挂（复位示例）
UICornerstone_SetBool(g_inst, panel, "transparent", 1);
4.16.7 控件的方法（核心引擎内部 API，点击展开）
本节为核心引擎 C++ 类（include/ 头文件）的公开方法，仅源码级集成（直接使用核心类）可调用。只使用 C ABI / C++ Binding 的用户请按「控件的属性」键名（Set*/Get*）与「控件的回调」事件名（SetCallback）等价操作。
方法参数
addControl(shared_ptr<Control>)添加子控件
handleEvent(Event)逆向遍历子控件分发事件
reflowChildren()按布局引擎重新计算全部子控件位置 / 尺寸
removeAllControls()移除全部子控件
resolveChildPercentages()解析子控件百分比尺寸（"50%" 形式）
setChildAnchorProps(Control*, AnchorInfo)子控件锚点布局属性
setChildFlowProps(Control*, FlowItemProps)子控件流式布局属性（flow-weight 等）
setChildGridProps(Control*, GridItemProps)子控件网格布局属性
setLayoutEngine(shared_ptr<LayoutEngine>) / getLayoutEngine()挂载 / 获取布局引擎（HFlow / VFlow / Anchor / Grid）
setRect(SRect) / resized(SRect)尺寸变更（resized 触发 reflow）
update() / draw()更新 / 绘制（背景 + 边框 + 子控件）

容器级滚轮事件（mouse-wheel）

滚轮落在 Panel 内且子控件未消费时，Panel 触发 mouse-wheel 回调（kEventMouseWheel）。载荷为 Float（GetValueChanged()）：+1 向上滚 / -1 向下滚（SDL 原生符号透传）。坐标在面板外不触发；子控件（如 ScrollBar/TextArea）已消费的滚轮不会重复回调。

panel.SetCallback("mouse-wheel", [](const Event& e) {
    float dy = e.GetValueChanged();   // +1 上 / -1 下
});
