4.17 ProgressBar（进度条）

ProgressBar 显示进度：水平 / 垂直方向、平滑动画（setValue 后的补间）、可选文本（None / Percent / Custom 三种模式，内部 Label）。继承链：ProgressBar → ControlImpl → Control。

缩放联动：进度文本为内部 Label（树成员），置于缩放画布（fit / stretch，见 5.6 视口画布缩放）时字号随复合缩放系数重建。

4.17.1 控件的创建

// C++
ProgressBar(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
ProgressBarBuilder(parent, SRect(50, 190, 300, 30))
    .setValue(75.0f).setTextMode(ProgressBarTextMode::Percent).build();

// C ABI
UIControlHandle bar = UICornerstone_CreateProgressBar(g_inst, 280, 193, 240, 95, 1.0f, 1.0f);

// JSON
{ "type": "progress-bar", "id": "loadProgress",
  "rect": { "x": 440, "y": 432, "w": 200, "h": 25 },
  "value": 65, "range": { "min": 0, "max": 100 },
  "style": "horizontal", "text-mode": "percent",
  "colors": { "progress": "#4080C0FF", "background": "#303030FF" } }

4.17.5 C++ Binding 样例

auto bar = ui->CreateProgressBar(280, 193, 240, 95);
bar.SetFloat(PropertyNames::kValue, 65.0f);
bar.SetFloat(PropertyNames::kRangeMax, 100.0f);
bar.SetEnum(PropertyNames::kTextMode, "percent");
bar.SetColor(PropertyNames::kProgress, UIColor{64, 128, 192, 255});   // UIColor = {r,g,b,a}
bar.SetCallback(PropertyNames::kEventValueChanged, [](const Event& e) {
    printf("value: %f\n", e.GetValueChanged());
});

// 核心库
auto p3 = ProgressBarBuilder(nullptr, SRect(50, 190, 300, 30))
    .setValue(75.0f)
    .setTextMode(ProgressBarTextMode::Percent)
    .setProgressColor({0, 128, 0, 255})
    .setBackgroundColor({50, 50, 50, 255})
    .setOnValueChanged([](shared_ptr, float, float value) {
        cout << "value changed to: " << value << endl;
    })
    .build();
BENCH->addControl(p3);

4.17.6 C ABI 调用样例

UIControlHandle bar = UICornerstone_CreateProgressBar(g_inst, 20, 20, 300, 20, 1.0f, 1.0f);

UICornerstone_SetFloat(g_inst, bar, "value", 40);
UICornerstone_SetFloat(g_inst, bar, "range-max", 100);
UICornerstone_SetEnum(g_inst, bar, "text-mode", "percent");  // custom / percent / none

static void onProgress(UIControlHandle ctl, const UIEventData* ev, void* ud) { }
UICornerstone_SetCallback(g_inst, bar, "value-changed", onProgress, NULL);
4.17.7 控件的方法（核心引擎内部 API，点击展开）
本节为核心引擎 C++ 类（include/ 头文件）的公开方法，仅源码级集成（直接使用核心类）可调用。只使用 C ABI / C++ Binding 的用户请按「控件的属性」键名（Set*/Get*）与「控件的回调」事件名（SetCallback）等价操作。
方法参数
getPercent()百分比 0-100（按动画值计算）
getTextLabel()内部文本 Label（可继续定制）
setAnimationSpeed(float) / getAnimationSpeed()动画速度（默认 0.1，范围 0.01-1.0）
setCustomText(string) / getCustomText()自定义文本
setFont(FontName) / setFontSize(int) / setAlignmentMode(AlignmentMode)文本字体 / 字号（默认 14）/ 对齐（默认 AM_CENTER）
setOnValueChanged(OnValueChangedHandler)回调 void(shared_ptr<ProgressBar>, float old, float value)
setProgressColor / setBackgroundColor / setTextColor(SColor)（+getter）颜色（默认绿 76,175,80 / 灰 200,200,200 / 白 255,255,255）
setRange(float min, float max)范围（默认 0-100）
setStyle(ProgressBarStyle) / getStyle()方向：Horizontal / Vertical
setTextMode(ProgressBarTextMode) / getTextMode()文本模式：None / Percent / Custom
setValue(float) / getValue()当前值（setValue 触发 value-changed 回调）
