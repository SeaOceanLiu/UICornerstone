4.18 ScrollBar（滚动条）

ScrollBar 是独立滚动条控件：滑块 + 轨道，支持垂直 / 水平方向、页大小（决定滑块长度，点击轨道翻一页）、步长与拖拽。也可内嵌于 TextArea / ComboBox 等控件内部。继承链：ScrollBar → ControlImpl → Control。

4.18.1 控件的创建

// C++
ScrollBar(Control* parent, SRect rect,
          ScrollBarOrientation orientation = ScrollBarOrientation::Vertical,
          float xScale = 1.0f, float yScale = 1.0f);
ScrollBarBuilder(parent, SRect(380, 100, 20, 200), ScrollBarOrientation::Vertical)
    .setRange(0, 1000).setPageSize(200).build();

// C ABI（orientation: 0=Vertical 1=Horizontal）
UIControlHandle sb = UICornerstone_CreateScrollBar(g_inst, 440, 472, 200, 16, 1, 1.0f, 1.0f);

// JSON
{ "type": "scroll-bar", "id": "hScroll",
  "rect": { "x": 440, "y": 472, "w": 200, "h": 16 },
  "orientation": "horizontal",
  "value": 30, "range": { "min": 0, "max": 100 },
  "page-size": 20, "step-size": 5, "thickness": 16,
  "events": { "onPositionChanged": "onScrollChanged" } }

4.18.3 控件的回调

事件名事件常量触发时机参数
position-changedkEventPositionChanged拖拽滑块、点击轨道翻页、setValue 导致位置变化时（value, pageSize, maxValue 等 4 个 float）
mouse-wheelkEventMouseWheel滚轮落在滚动条上直接步进 value ± step-size（向上滚 value 减，经 range clamp）；滚轮在滚动条外时事件由所在 Panel 容器级 mouse-wheel 回调接手Float（scrollY，+1 向上 / -1 向下）

4.18.5 C++ Binding 样例

Control sb = ui->CreateScrollBar(440, 472, 200, 16, 1 /*horizontal*/);
sb.SetFloat(PropertyNames::kValue, 30.0f);
sb.SetFloat(PropertyNames::kPageSize, 20.0f);
sb.SetCallback(PropertyNames::kEventPositionChanged, [](const Event& e) {
    printf("pos: %f\n", e.GetPositionChanged());
});

// 核心库
auto vScrollBar = ScrollBarBuilder(nullptr, SRect(380, 100, 20, 200), ScrollBarOrientation::Vertical)
    .setRange(0, 1000).setPageSize(200).setValue(0)
    .setOnPositionChanged([](shared_ptr sb, float value, float pageSize, float maxValue) {
        cout << "Scroll position: " << value << endl;
    })
    .build();
BENCH->addControl(vScrollBar);

4.18.6 C ABI 调用样例

// orientation: 0=垂直, 1=水平
UIControlHandle sb = UICornerstone_CreateScrollBar(g_inst, 20, 20, 12, 200, 0, 1.0f, 1.0f);

UICornerstone_SetFloat(g_inst, sb, "range-min", 0);
UICornerstone_SetFloat(g_inst, sb, "range-max", 1000);
UICornerstone_SetFloat(g_inst, sb, "value", 250);
UICornerstone_SetFloat(g_inst, sb, "page-size", 100);

static void onPosChanged(UIControlHandle ctl, const UIEventData* ev, void* ud) {
    /* ev->data.doubleVal 为滚动位置 */
}
UICornerstone_SetCallback(g_inst, sb, "position-changed", onPosChanged, NULL);
4.18.7 控件的方法（核心引擎内部 API，点击展开）
本节为核心引擎 C++ 类（include/ 头文件）的公开方法，仅源码级集成（直接使用核心类）可调用。只使用 C ABI / C++ Binding 的用户请按「控件的属性」键名（Set*/Get*）与「控件的回调」事件名（SetCallback）等价操作。
方法参数
isDragging()是否拖拽中
onMouseEnter / onMouseLeave(x, y)悬停状态（override）
setOnPositionChanged(OnPositionChangedHandler)位置变化回调 void(shared_ptr<ScrollBar>, float value, float pageSize, float maxValue, ...)
setOrientation(ScrollBarOrientation) / getOrientation()方向
setPageSize(float) / getPageSize()页大小（滑块长度；点击轨道翻一页）
setRange(float min, float max) / getMinValue() / getMaxValue()滚动范围
setStepSize(float)步长（方向键/箭头）
setThickness(float) / getThickness()滚动条宽度（默认 SCROLLBAR_WIDTH=16）
setValue(float) / getValue()当前滚动位置
shouldShow()是否应显示（按内容/视口比例计算）
