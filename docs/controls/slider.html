4.20 Slider（滑块）

Slider 是拖拽取值控件：水平 / 垂直方向、反向模式、步长吸附（松手 Snap-on-Release）、刻度标记、可选数值标签（内部 Label，支持自定义格式）。继承链：Slider → ControlImpl → Control。

缩放联动：刻度字体随复合缩放系数懒加载重建（字体数据复用，无重复 IO）；数值标签为内部 Label 随树自动重建。详见 5.6.6。

4.20.1 控件的创建

// C++
Slider(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
SliderBuilder(parent, SRect(HX, 40, 250, 20)).setRange(0, 100).setValue(50).setShowValueLabel(true).build();

// C ABI
UIControlHandle slider = UICornerstone_CreateSlider(g_inst, 29, 224, 257, 20, 0, 255, 255, 1.0f, 1.0f);

// JSON
{ "id": "rSlider", "type": "slider",

4.20.5 C++ Binding 样例

Control slider = ui->CreateSlider(20, 20, 300, 30, 0, 100, 50);
slider.SetFloat(PropertyNames::kValue, 50.0f);
slider.SetBool(PropertyNames::kShowValueLabel, true);
slider.SetString(PropertyNames::kLabelFormat, "%.0f px");
slider.SetEnum(PropertyNames::kSliderStyle, PropertyNames::kOrientHorizontal);
slider.SetCallback(PropertyNames::kEventValueChanged, [](const Event& e) {
    printf("value = %.1f\n", e.GetValueChanged());
});

// 核心库
auto s1 = SliderBuilder(nullptr, SRect(HX, 40, 250, 20))
    .setRange(0, 100).setValue(50).setShowValueLabel(true)
    .setOnValueChanged([](shared_ptr s, float v) {
        cout << "Slider1 value changed to: " << v << endl;
    })
    .build();
BENCH->addControl(s1);

4.20.6 C ABI 调用样例

// 创建即带 min / max / 当前值
UIControlHandle sl = UICornerstone_CreateSlider(g_inst, 20, 20, 260, 20, 0, 100, 50, 1.0f, 1.0f);

UICornerstone_SetFloat(g_inst, sl, "value", 75);
UICornerstone_SetFloat(g_inst, sl, "step", 5);
UICornerstone_SetBool(g_inst, sl, "show-value-label", 1);

static void onSlide(UIControlHandle ctl, const UIEventData* ev, void* ud) {
    /* ev->data.doubleVal / floatVal 为新值 */
}
UICornerstone_SetCallback(g_inst, sl, "value-changed", onSlide, NULL);
