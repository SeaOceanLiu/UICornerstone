4.22 StatusBar（状态栏）

VSCode 风格底部状态栏：左右对齐的「段」，每段可显示文本/图标（任意控件），可点击（回调或弹出 MenuPanel 菜单）。继承链：StatusBar → ControlImpl → Control。设计文档见 design/StatusBar_Design.md。

4.22.1 控件的创建

// C++
auto bar = StatusBarBuilder(nullptr, SRect(0, 876, 1400, 24))
               .addStatusItem("branch", u8"main", false)
               .addStatusItem("enc", u8"UTF-8", true).build();

// C ABI
UIControlHandle bar = UICornerstone_CreateStatusBar(g_inst, 0, 876, 1400, 24, 1, 1);
UICornerstone_StatusBarAddItem(g_inst, bar, "branch", u8"main", 0);

// JSON
{ "type": "status-bar", "rect": [0, 876, 1400, 24], "font-size": 13,
  "items": [ {"id": "branch", "text": "main"},
             {"id": "enc", "text": "UTF-8", "align": "right"} ] }

属性/字段属性常量类型默认值说明
fontSizekFontSizeInt13段文字字号

4.22.3 控件的回调 / 事件

事件名事件常量触发时机参数
onClickkEventStatusItemClick（"status-item-click"）点击无菜单段intVal = 段索引（从左起）
图标槽几何居中（内容无关基准）；文字型图标受字体基线偏移影响，建议用 Shape 等几何内容。弹窗菜单点击项自动关闭；外部点击/Esc 关闭为后续增强。

4.22.4 JSON 语法

{
  "type": "status-bar", "id": "sb", "rect": { "x": 0, "y": 876, "w": 1400, "h": 24 },
  "font-size": 13, "item-height": 24,
  "items": [
    { "id": "branch", "text": "main", "icon": "provider:icons/git",
      "menu": "#branchMenu" },
    { "id": "enc", "text": "UTF-8", "align": "right" }
  ]
}
JSON 键类型说明
items[].alignEnumleft（默认）/ right 段对齐
items[].icon资源引用段图标（任意控件/Actor）
items[].menuMenuPanel id点击弹出菜单
items[].onClick动作名点击事件（C ABI 经 status-item-click，见 4.22.3）

4.22.5 C++ Binding 样例

auto bar = ui->CreateStatusBar(0, 876, 1400, 24);
bar.SetString(PropertyNames::kItemId, "branch");   // 段定位后属性分发
bar.SetInt(PropertyNames::kFontSize, 13);   // int 通道

4.22.6 C ABI 调用样例

UIControlHandle bar = UICornerstone_CreateStatusBar(g_inst, 0, 876, 1400, 24, 1.0f, 1.0f);
UICornerstone_StatusBarAddItem(g_inst, bar, "branch", u8"main", 0);
UICornerstone_StatusBarAddItem(g_inst, bar, "enc", u8"UTF-8", 1);
UICornerstone_StatusBarSetItemText(g_inst, bar, "branch", u8"dev");
UICornerstone_SetInt(g_inst, bar, "font-size", 13);    // int 通道
4.22.7 控件的方法（核心引擎内部 API，点击展开）
本节为核心引擎 C++ 类（include/ 头文件）的公开方法，仅源码级集成（直接使用核心类）可调用。只使用 C ABI / C++ Binding 的用户请按「控件的属性」键名（Set*/Get*）与「控件的回调」事件名（SetCallback）等价操作。
方法参数
addStatusItem(id, text, rightAlign)添加段
updateStatusItemText(id, text)更新段文本
removeStatusItem(id)移除段
getStatusItem(id)段对象访问（StatusItem*）
setStatusItemMenu(id, menuPanel)段绑定弹窗菜单
setStatusItemLeadingControl(id, ctl)段绑定图标（任意控件）
setStatusItemOnClick(id, cb)段点击回调
setFontSize(px) / setItemHeight(px)外观（触发 relayout）
openPopup(index) / closePopup() / isPopupOpen() / getPopupPanel()弹窗控制
setXxxProperty / getXxxProperty（override）属性分发
