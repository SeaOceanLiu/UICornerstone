4.23 TabControl（选项卡）

TabControl 多页签控件：页签条四方向（上/下/左/右），页面为任意控件子树。两层焦点作用域：Tab 在页内控件循环，Ctrl+Tab 在「页签条 ↔ 页内」间切换。继承链：TabControl → ControlImpl → Control。设计文档见 design/TabControl_Design.md。

4.23.1 控件的创建

// C++
auto tc = TabControlBuilder(nullptr, SRect(120, 80, 560, 240))
              .addTab(u8"主页", page1).addTab(u8"设置", page2).build();

// C ABI
UIControlHandle tc = UICornerstone_CreateTabControl(g_inst, 120, 80, 560, 240, 1, 1);
UICornerstone_TabAddPage(g_inst, tc, u8"主页");

// JSON
{ "type": "tab-control", "rect": {"x":120,"y":80,"w":560,"h":240}, "position": "top",
  "tabs": [ {"title": "主页", "page": {"type": "panel"}} ],
  "events": { "onTabChange": "onTab" } }

4.23.2 控件的属性

属性/字段属性常量类型默认值说明
positionkTabPositionEnumtoptop / bottom / left / right
fontSizekFontSizeInt13页签文字字号
currentIndexkTabCurrentIndexInt0当前页（首页自动选中）

4.23.3 控件的回调 / 事件

事件名事件常量触发时机参数
onTabChangekEventTabChanged（"tab-changed"）页签切换（setCurrentIndex / 点击 / 键盘）intVal = 新页索引

4.23.4 键盘导航

页签条获焦：←/→（或竖排 ↑/↓）循环切换、Home/End 首尾；Tab 层内循环（页内控件间 / 页签条+外部）；Ctrl+Tab 层切换（页内 ↔ 页签条）。

4.23.5 JSON 语法

{
  "type": "tab-control", "id": "tabs", "rect": { "x": 120, "y": 80, "w": 560, "h": 240 },
  "position": "top", "font-size": 13, "currentIndex": 0,
  "tabs": [
    { "title": "主页", "icon": "provider:icons/home", "page": { "type": "panel" } },
    { "title": "设置", "page": { "type": "panel" } }
  ],
  "events": { "onTabChange": "onTab" }
}
JSON 键类型说明
tabs[].icon资源引用页签图标

4.23.6 C++ Binding 样例

auto tc = ui->CreateTabControl(120, 80, 560, 240);
tc.SetEnum(PropertyNames::kTabPosition, PropertyNames::kTabPositionTop);
tc.SetInt(PropertyNames::kTabCurrentIndex, 0);
tc.SetCallback(PropertyNames::kEventTabChanged, onTab);

4.23.7 C ABI 调用样例

UIControlHandle tc = UICornerstone_CreateTabControl(g_inst, 120, 80, 560, 240, 1.0f, 1.0f);
int idx = UICornerstone_TabAddPage(g_inst, tc, u8"主页");
UIControlHandle pg = UICornerstone_CreatePanel(g_inst, 0, 0, 100, 100, 1.0f, 1.0f);
UICornerstone_TabSetPage(g_inst, tc, idx, pg);
UICornerstone_SetEnum(g_inst, tc, "position", "top");
4.23.8 控件的方法（核心引擎内部 API，点击展开）
本节为核心引擎 C++ 类（include/ 头文件）的公开方法，仅源码级集成（直接使用核心类）可调用。只使用 C ABI / C++ Binding 的用户请按「控件的属性」键名（Set*/Get*）与「控件的回调」事件名（SetCallback）等价操作。
方法参数
addTab(title, page) / insertTab(index, …) / removeTab(index)页写（removeTab 钳制 currentIndex）
getTabCount() / getTabs()页只读访问
setCurrentIndex(i) / getCurrentIndex()切换（触发 onTabChange + 页面显隐）
setTabText(i, title) / setTabPage(i, page) / setTabLeadingControl(i, ctl)页内容（触发 relayout）
setPosition(TabPosition) / getPosition()四方向（触发 relayout）
setFontSize(px) / getFontSize()页签字号（重建字体 + relayout）
setOnTabChange(cb)切换回调 (shared_ptr<TabControl>, int)
setXxxProperty / getXxxProperty（override）属性分发（position/current-index/font-size）
