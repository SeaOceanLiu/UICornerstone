4.24 TextArea（多行文本输入）

TextArea 是多行文本输入控件：按 \n 分行 + 自动换行（word wrap）、垂直 / 水平内置滚动条、光标与选区、剪贴板（Ctrl+C/V/X）。继承链：TextArea → EditBox → ControlImpl → Control（继承 EditBox 全部文本能力）。

缩放联动：置于缩放画布（fit / stretch，见 5.6 视口画布缩放）时，字号随复合缩放系数重建；滚动范围保持本地语义恒定，不随字号漂移。

4.24.1 控件的创建

// C++
TextArea(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
TextAreaBuilder(parent, SRect(750, 360, 200, 100), 2.0f, 2.0f)
    .setText("2x scaled TextArea").setWordWrap(true).setLineHeight(22).build();

// C ABI
UIControlHandle ta = UICornerstone_CreateTextArea(g_inst, 5, 5, 750, 160, 1.0f, 1.0f);

// JSON
{ "type": "text-area", "id": "notesTextArea",
  "rect": { "x": 20, "y": 432, "w": 200, "h": 80 },
  "placeholder": "Multi-line notes...",
  "word-wrap": true,
  "font": { "size": 12 },
  "colors": { "background": { "normal": "#353535FF" }, "border": { "normal": "#606060FF" } },
  "events": { "onTextChanged": "onNotesChanged" } }

4.24.5 C++ Binding 样例

Control ta = ui->CreateTextArea(20, 432, 200, 80);
ta.SetString(PropertyNames::kText, "Hello from TextArea!\nEdit me.");
ta.SetBool(PropertyNames::kWordWrap, true);
ta.SetCallback(PropertyNames::kEventTextChanged, [](const Event& e) {
    printf("text: %s\n", e.GetTextChanged().c_str());
});

// C++ 核心库
auto ta2 = TextAreaBuilder(nullptr, SRect(750, 360, 200, 100), 2.0f, 2.0f)
    .setText("2x scaled TextArea")
    .setWordWrap(true).setLineHeight(22)
    .setOnTextChanged([](shared_ptr, string text) {
        cout << "TextArea changed" << endl;
    })
    .build();
BENCH->addControl(ta2);
滚动条内置于控件底部 / 右侧，内容超出时自动显示。

4.24.6 C ABI 调用样例

UIControlHandle ta = UICornerstone_CreateTextArea(g_inst, 20, 20, 300, 200, 1.0f, 1.0f);

UICornerstone_SetString(g_inst, ta, "text", "第一行\n第二行");
UICornerstone_SetBool(g_inst, ta, "read-only", 1);
UICornerstone_SetBool(g_inst, ta, "word-wrap", 1);

static void onTextChanged(UIControlHandle ctl, const UIEventData* ev, void* ud) { }
UICornerstone_SetCallback(g_inst, ta, "text-changed", onTextChanged, NULL);
