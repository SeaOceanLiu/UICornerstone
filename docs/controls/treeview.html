4.25 TreeView（树形视图）

TreeView 是层级数据展示控件：节点（TreeNode）支持展开/折叠、选中、滚动（垂直 + 水平）、键盘环行导航与选中项滚动定位。 继承链：TreeView → ControlImpl → Control。字号随复合缩放重建；行高独立不随字号（见 5.6.6）。

4.25.1 控件的创建

// C++
TreeView(Control* parent, const SRect& rect, float xScale = 1.0f, float yScale = 1.0f);
auto tree = TreeViewBuilder(BENCH.get(), {20, 20, 240, 300})
    .setItems({ makeNode("root", "Root", true, { makeNode("child1", "Child 1") }) })
    .setOnSelect([](shared_ptr<TreeView>, const string& id) { ... })
    .build();

// C ABI
UIControlHandle tree = UICornerstone_CreateTreeView(g_inst, 20, 20, 240, 300, 1.0f, 1.0f);
// 节点数据经 SetString(PropertyNames::kItems, json) 填充

// JSON
{ "id": "tree", "type": "tree-view",
  "rect": { "x": 20, "y": 20, "w": 240, "h": 300 },
  "font": { "size": 16, "name": "harmonyos-sans-sc-regular" },   // v1.1.1 通用字体键（亦可 "font-size":16）
  "items": [ { "id": "root", "label": "Root", "expanded": true,
               "children": [ { "id": "child1", "label": "Child 1" } ] } ],
  "events": { "onSelect": "onTreeSelect" } }
字体（v1.1.1）：font（对象 {name,size,style}）/ fontSize 为通用键；未声明时沿父控件链继承最近显式字体（如父 Panel 设 font:{size:20} 则树默认 20）。

4.25.2.1 item 级属性（C ABI，item-id 定位模式）

TreeNode 不是 Control，item 级属性经 TreeView 按 item-id 定位目标节点后再读写 （先 SetString("item-id", id)，随后 set/get 作用于该节点）：

属性属性常量类型默认值说明
item-fontkTreeItemFontEnum继承 TreeView逐 Item 字体枚举（如 maplemono-nf-cn-regular 粗体）
item-font-sizekTreeItemFontSizeInt0逐 Item 字号（0 = 继承 TreeView 级）
item-idkTreeItemIdString—定位目标节点（后续 item 级属性的作用对象）
item-leading-controlkTreeItemLeadingControlPtr—行前置控件容器句柄（借用语义，生命周期由调用方保证；类型经 UICornerstone_GetControlType / Binding Control::GetType() 查询，如 "check-box" / "image"，再经通用属性系统操作：GetBool(ctl, "checked") / SetCallback(ctl, "check-changed", ...)；C++ Binding 用 ui->FromHandle(lc) 包装代理）。运行时 SetPtr 立即挂树（结构变更之外无需等待重建），传 NULL 解除容器并摘树

item-leading-alignkTreeItemLeadingAlignEnumkAlignLowerMidLeft槽位对齐（复用 Label 9 宫格：kAlignLowerTopLeft/kAlignLowerMidLeft/kAlignLowerBottomLeft ...；水平分量忽略，槽位贴文本起点；垂直：顶/中/底）

4.25.4.25 item 增强（行前置控件容器 + 逐 Item 字体）

"items": [
  { "id": "cb1", "label": "带勾选框的行",
    "leadingControl": { "type": "check-box", "check-state": "checked", "id": "cb_n2" },
    "leadingGap": 10 },
  { "id": "img1", "label": "带图标的行",
    "leadingControl": { "type": "image", "image": "assets/images/cross_down.png" },
    "font": "maplemono-nf-cn-regular", "size": 16 }
]
  • leadingControl：行前置控件容器（控件 JSON，复用 type + 控件属性，如 check-box / image）。rect 由 TreeView 自适应（高 = 行内文字高度，宽按原始宽高比等比， 行内垂直居中）；文字缩进 = 无容器时文本的缩进，文字被容器让位右移；有箭头行箭头在容器 左侧不重叠。给容器指定 id 后可直接 FindControl(inst, id) 拿到句柄 （通用属性系统操作任意控件）。
  • leadingGap：容器与文本之间的间隔（局部 px，默认 6）。
  • font / size：逐 Item 字体枚举（如 maplemono-nf-cn-regular 粗体）/ 字号（0 = 继承 TreeView 级）。

4.25.5 C++ Binding 样例

Control tree = ui->CreateTreeView(20, 20, 240, 300);
tree.SetString(PropertyNames::kItems,
    R"([{"id":"root","label":"Root","expanded":true,
         "children":[{"id":"child1","label":"Child 1"}]}])");
tree.SetCallback(PropertyNames::kEventSelect, [](const Event& e) {
    printf("select: %s\n", e.GetNodeId().c_str());
});

4.25.6 C ABI 调用样例

UIControlHandle tree = UICornerstone_CreateTreeView(g_inst, 20, 20, 240, 300, 1.0f, 1.0f);

UICornerstone_SetString(g_inst, tree, "items",
    "[{\"id\":\"root\",\"label\":\"Root\",\"expanded\":true,"
    "\"children\":[{\"id\":\"child1\",\"label\":\"Child 1\"}]}]");

static void onSelect(UIControlHandle ctl, const UIEventData* ev, void* ud) {
    /* ev 负载含选中节点 id */
}
UICornerstone_SetCallback(g_inst, tree, "select", onSelect, NULL);

// item 级属性：item-id 定位 → 读写
UICornerstone_SetString(g_inst, tree, "item-id", "img1");
UICornerstone_SetFloat( g_inst, tree, "item-leading-gap", 10.0f);   // 容器与文本间隔
UICornerstone_SetInt(   g_inst, tree, "item-font-size", 18);
UICornerstone_SetEnum(  g_inst, tree, "item-font", "maplemono-nf-cn-regular");  // 粗体
UICornerstone_SetEnum(  g_inst, tree, "item-leading-align", "bottom-left");    // 槽位贴行底
float gap = 0;
UICornerstone_GetFloat( g_inst, tree, "item-leading-gap", &gap);

// 读取行内 CheckBox 状态（经容器句柄 + 通用属性系统）
void* lc = NULL;
UICornerstone_SetString(g_inst, tree, "item-id", "cb1");
UICornerstone_GetPtr(   g_inst, tree, "item-leading-control", &lc);
char ctype[64] = {0};
UICornerstone_GetControlType(g_inst, lc, ctype, (int)sizeof(ctype));  // "check-box" / "image" ...
int checked = 0;
UICornerstone_GetBool(  g_inst, lc, "checked", &checked);           // 1 = 勾选
UICornerstone_SetBool(  g_inst, lc, "checked", 1);                   // 反向设置
// 或 JSON 里容器带 id 时直接全局查找：
void* cb = UICornerstone_FindControl(g_inst, "cb_n2");
