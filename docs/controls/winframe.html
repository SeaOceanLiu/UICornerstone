4.26 WinFrame（可拖拽缩放的窗口容器）

WinFrame 是应用内「窗口」容器：标题栏拖拽移动、边缘八方向缩放、焦点作用域边界（Ctrl+Tab 切换）、点击置顶、关闭按钮。继承链：WinFrame → Panel → ControlImpl → Control。

4.26.1 控件的创建

// C++
WinFrame(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
WinFrameBuilder(parent, SRect(100, 100, 400, 300))
    .setTitle("My Window").setTitleFontSize(24).setEdgeMargin(6.0f).setOnClose(cb).build();

// C ABI
UIControlHandle wf = UICornerstone_CreateWinFrame(g_inst, "Resizable WinFrame", 100, 100, 400, 300, 1.0f, 1.0f);

// C++ Binding
auto wf = ui->CreateWinFrame("Resizable WinFrame", 100, 100, 400, 300);

// JSON（解析后默认隐藏，需 show；children 自动加入客户区）
{ "type": "win-frame", "id": "resultWinFrame",
  "rect": { "x": 200, "y": 100, "w": 400, "h": 300 },
  "title": "Submitted", "edge-margin": 4.0,
  "colors": { "title-bar": { "bg": { "normal": "#2A2A50FF" } },
              "title-text": { "normal": "#FFFFFFFF" } },
  "children": [ { "type": "label", "caption": "Form submitted successfully!" } ] }

4.26.5 C++ Binding 样例

auto wf = ui->CreateWinFrame("Resizable WinFrame", 100, 100, 400, 300);
wf.SetString(PropertyNames::kTitle, "My Window");
wf.SetFloat(PropertyNames::kEdgeMargin, 6.0f);
wf.SetBool(PropertyNames::kResizable, true);
wf.SetCallback(PropertyNames::kEventClose, [](const Event&) {
    printf("window closed\n");
});
// 向客户区加控件
auto lbl = ui->CreateLabel("Form content", 14.0f, 20, 30, 240, 60);
wf.AddChild(lbl);
常量：MIN_WIDTH=100、MIN_HEIGHT=60（缩放钳制）；行为：标题栏拖拽、4px 边缘八方向缩放、边缘双箭头光标、show/点击置顶、焦点作用域边界。

4.26.6 C ABI 调用样例

// 窗口框架：可容纳子控件（如仪表盘弹窗）
UIControlHandle wf = UICornerstone_CreateWinFrame(g_inst, "Settings", 100, 100, 360, 240, 1.0f, 1.0f);

UICornerstone_SetString(g_inst, wf, "title", "设置");
UICornerstone_SetBool(g_inst, wf, "resizable", 1);
UICornerstone_SetBool(g_inst, wf, "close-on-esc", 1);

static void onClose(UIControlHandle ctl, const UIEventData* ev, void* ud) { }
UICornerstone_SetCallback(g_inst, wf, "close", onClose, NULL);
