3.4 声明式 UI

声明式 UI 是 UICornerstone 的核心工作流：用 JSON 描述控件树、布局、事件与主题，运行时由 LayoutParser 解析构建控件树。界面结构一目了然、可热重载、可被外部工具生成。

3.4.1 声明式 UI 介绍

一个布局文件描述整个界面：

{
  "version": "1.0",
  "viewport": { "width": 800, "height": 480 },
  "theme": {
    "fonts": { "default": { "name": "HarmonyOS_Sans_SC_Regular", "size": 16 } },
    "colors": { "background": "#282828FF", "text": "#FFFFFFFF" }
  },
  "controls": [
    {
      "type": "button", "id": "submitBtn",
      "rect": { "x": 280, "y": 140, "w": 100, "h": 35 },
      "caption": "Submit",
      "events": { "onClick": "handleSubmit" }
    }
  ]
}

通用节点键

键说明
children子控件数组（容器类型）
colors状态色对象：{"background":{"normal","hover","pressed","disabled"}}，含 text / border / text-shadow / 控件特有键
events{"onClick":"handlerName"} 引用已注册处理器
id全局唯一标识，供 FindControl / findControlById 查找
margin{"left","top","right","bottom"}
rect{"x","y","w","h"}；支持百分比字符串（"50%"）
scale{"x":1.0,"y":1.0} 本地缩放
type控件类型（kebab 小写）：label / button / image / image-button / animation / edit-box / check-box / combo-box / context-menu（控件级 context-menu 键）/ list-view / numeric-up-down / progress-bar / scroll-bar / shape / status-bar / tab-control / color-picker / text-area / panel / menu-bar / win-frame / splitter / tree-view
visible / enabled可见 / 启用

颜色格式："#RGB" / "#RRGGBB" / "#RRGGBBAA"，或 {"r":255,"g":0,"b":0,"a":128}。

加载与事件绑定

// C ABI
UICornerstone_RegisterAction(g_inst, "handleSubmit",
    [](UIControlHandle ctl, void* user){ /* ... */ }, NULL);
UICornerstone_LoadLayout(g_inst, LAYOUT_JSON);   // 或 LoadLayoutFromFile

// C++ Binding
ui->RegisterAction("handleSubmit", [](Control ctl){ /* ... */ });
ui->LoadLayout(layoutJson);
未注册的 handler 名会被静默跳过，便于同一布局文件在不同工程中复用。

3.4.2 声明式 UI 的布局

布局由面板的 layout 键启用，四种引擎：

流式（h-flow / v-flow）

"layout": { "type": "h-flow", "gap": 4,
             "padding": { "left": 4, "top": 4, "right": 4, "bottom": 4 } }

子控件以 flow-weight 弹性分配剩余空间（>0 弹性，0/缺省为固定尺寸）。

{
  "type": "panel", "id": "formPanel",
  "rect": { "x": 50, "y": 112, "w": 400, "h": 200 },
  "layout": { "type": "v-flow", "gap": 8 },
  "children": [
    { "type": "edit-box",  "id": "nameEdit", "flow-weight": 1, "rect": { "w": 0, "h": 30 } },
    { "type": "button",    "id": "submitBtn","rect": { "w": 100, "h": 35 } }
  ]
}

锚点（anchor）

"layout": { "type": "anchor" }
// 子控件：
{ "type": "button", "id": "okBtn",
  "rect": { "w": 100, "h": 32 },
  "anchor": "top-right",
  "anchorOffset": { "left": 10, "top": 10, "right": 0, "bottom": 0 } }

锚点值：top-left / top-center / top-right / mid-left / center / mid-right / bottom-left / bottom-center / bottom-right / top-stretch / bottom-stretch / left-stretch / right-stretch / fill。

anchor 取值含义

取值（小写连字符）含义
top-left / top-center / top-right靠顶部：左/中/右对齐（top-left/top-right 用 offset.left+top / offset.right+top 定距）
mid-left / center / mid-right垂直居中：左/中/右对齐（center 居中后 offset.left+top 额外位移）
bottom-left / bottom-center / bottom-right靠底部：左/中/右对齐（offset.bottom 定底距）
top-stretch顶部拉伸：宽度填满容器（扣 offset.left+right），顶部固定
bottom-stretch底部拉伸：宽度填满容器，底部固定
left-stretch左侧拉伸：高度填满容器（扣 offset.top+bottom），左侧固定
right-stretch右侧拉伸：高度填满容器，右侧固定
fill填满容器内边距区域（宽高均填满，扣四边 offset 与布局 padding）

网格（grid）

"layout": {
  "type": "grid",
  "columns": ["1fr", "2fr", "100px"],
  "rows": ["30px", "1fr", "auto"]
}
// 子控件：
{ "type": "button", "id": "cellBtn",
  "grid": { "row": 0, "col": 1, "rowSpan": 1, "colSpan": 1 } }

行列尺寸支持 Fixed（"100px"） / Flex（"1fr"） / Auto（"auto"） 三种。

重排时机：Panel::setRect() 与窗口 resize 自动触发 reflowChildren()；visible==false 的子控件被跳过。

3.4.3 声明式 UI 的组件逻辑

通过 components 定义可复用组件模板，在 layouts 中实例化：

{
  "components": {
    "SearchBar": {
      "props": { "placeholder": "Search...", "btnText": "Go" },
      "template": {
        "type": "panel", "layout": { "type": "h-flow", "gap": 4 },
        "children": [
          { "type": "edit-box", "id": "$search", "rect": { "w": 200, "h": 30 },
            "placeholder": "$props.placeholder" },
          { "type": "button", "id": "$go", "rect": { "w": 60, "h": 30 },
            "caption": "$props.btnText", "events": { "onClick": "onSearch" } }
        ]
      }
    }
  },
  "layouts": [
    { "use": "SearchBar", "id": "topSearch",
      "props": { "placeholder": "输入关键词", "btnText": "搜索" },
      "rect": { "x": 20, "y": 20, "w": 300, "h": 40 } }
  ]
}
组件系统会将组件中的控件（$id 形式）实例化到 layouts 数组指定的布局中；事件处理器同样经 RegisterAction 注册。

3.4.5 主题样式

顶层 theme 键提供全局默认样式，控件节点上的显式键优先。应用顺序：主题默认 → 公共 colors → 控件专用颜色 → 控件专用字体。

"theme": {
  "colors": {
    "background": "#282828FF",
    "text": "#FFFFFFFF",
    "border": "#808080FF",
    "button": {
      "bg":    { "normal": "#3C3C3CFF", "hover": "#4C4C4CFF", "pressed": "#2C2C2CFF" },
      "border":{ "normal": "#505050FF" },
      "text":  { "normal": "#FFFFFFFF" }
    },
    "checkbox": { "check-color": "#66BB6AFF", "cross-color": "#FF5722FF", "box-border-color": "#53535AFF" },
    "progressbar": { "progress": "#66BB6AFF", "track": "#333333FF" }
  },
  "fonts": {
    "default": { "name": "HarmonyOS_Sans_SC_Regular", "size": 16 },
    "button":  { "size": 16 }
  }
}

支持类别（category）：button / label / editbox / textarea / checkbox / progressbar / panel / scrollbar / menubar；字体未定义时回退 default，再回退内置默认（HarmonyOS Sans SC Regular 16）。

3.4.6 热加载

HotReloader 监视布局文件，改动即热重载，无需重启程序：

// 文件变化 → 完全重建控件树（Handler 保留）
HotReloader reloader("layouts/main.json", [](){
    // 重建逻辑：removeAllControls → parseLayoutFile → addControl
});
reloader.poll();      // 每帧调用，默认 30 帧检查一次（≈0.5s）
reloader.reload();    // 或手动触发
reloader.setPollInterval(15);   // 调整检查间隔（帧数）
热重载会重建整棵控件树：控件状态（选中、输入内容）不保留；仅支持单文件轮询监视。适合开发期调整布局/样式。

3.4.7 资源提供者（ResourceProviders）

支持在初始化前把资源读入内存注册（MemoryResourceProvider），或经布局顶层 resourceProviders 键把磁盘路径挂载为资源名（懒加载 + 缓存）。挂载后控件引用一律使用 provider: 前缀，引擎在 loadFromFile 入口自动分流，绝不触碰磁盘（挂载点在 controls 之前）：

{
  "version": "1.0",
  "resourceProviders": [
    { "name": "up-image", "path": "images/cross_up.png" },
    { "name": "bomb-ani", "path": "animations/bombBlock/bombBlock.jsonc" }
  ],
  "controls": [ ... ]
}

引用语法（与 C ABI 属性 / 工厂等价）：

// ① image-button 状态图：actors 对象式（providerName）或字符串式（provider:）
{ "type": "image-button",
  "actors": {
    "normal":  { "providerName": "up-image" },
    "hover":   "provider:cross-down",
    "pressed": { "providerName": "up-image" }
  } }

// ② 动画描述 path
{ "type": "animation", "path": "provider:bomb-ani" }

// ③ 独立图片节点（Actor）：image 键（文件路径）或 image-resource / providerName（内存资源 ID）
{ "type": "image", "id": "hero", "rect": { "x": 20, "y": 20, "w": 128, "h": 128 },
  "image": "assets/images/cross_up.png", "scale-type": "fit-center" }
{ "type": "image", "rect": { "x": 160, "y": 20, "w": 64, "h": 64 },
  "providerName": "cross-down", "match-parent-rect": false }

通用字体键（v1.1.1）：任意控件均可在其 JSON 上声明 font（对象 {name, size}）或便捷键 font-size： 未声明时沿父控件链继承最近一次显式字体（含字号），父控件自身未声明时沿用主题默认。示例：Panel 上 font:{size:20} → 其内 Label/EditBox/TreeView/ListView 等无字体声明的子控件自动 20；子级 font:{size:24} 覆盖。字串形式（font-name 枚举）用于部分控件的 name 子键。

继承细节：仅当祖先显式声明 font.name 时才会把字体名传给子控件；父只声明 font-size（未声明 name）时，子控件保留自身默认字体名（如 ListView 默认 HarmonyOS_Sans_SC_Regular）。

控件继承方式
Label / EditBox / ComboBox / TextArea / ProgressBar / TreeView / TabControl / StatusBar / MenuBar / ListView直接承接（ApplyFontToControl 直连 setFontSize/setFont）
Button / CheckBox / WinFrame / ColorPicker / Dialog（含确认按钮）内部 Label 子控件经父链透传继承（文字载体为内部 Label）
Slider 数值标签专用 label-font 键（kLabelFont），独立于通用继承——数值标签字号可单独调
Panel / ScrollBar / Splitter / Shape / Image / Actor / LuotiAni / HandleControl / ContextMenu无文字渲染，不涉及

Label 字体三形态（font 枚举、font-resource 内存资源、font-file 任意路径）与字符串属性互斥覆盖，均可带 provider: 前缀：

{ "type": "label", "caption": "Hello",
  "font-resource": "maple-font", "font-size": 20 }        // 内存注册的字体 ID
{ "type": "label", "caption": "Hello",
  "font-file": "fonts/MyCustom.ttf" }                    // 任意字体文件（相对 resourceRoot）
{ "type": "label", "caption": "Hello",
  "font-file": "provider:maple-font" }                   // 文件形态走内存注册
内存 provider 模式下引擎不读磁盘：resourceRoot 指向不存在目录也可运行，全部资源（含动画 JSON 内层图片 src 原串，如 animations/bombBlock/marker.svg）须按原串注册进 provider。provider: 是保留前缀，请勿用作真实文件名。
