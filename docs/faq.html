12 常见问题（FAQ）

Q1: 用哪个后端？

SDL3。功能最全（多窗口、渲染器探测、四能力位）。要求单 DLL 极简部署选 raylib（注意单窗口限制）；偏好 C++ 风格 API 选 SFML。

Q2: 声明式 UI 和程序化 UI 怎么选？

界面结构固定、想热重载、想分离设计与代码 → JSON 声明式。动态拼装、运行时高频增删控件、偏好强类型 → 程序化（C ABI 工厂或 C++ Builder）。两者可混用：JSON 建框架，代码再按 id 找控件改属性。

Q3: C++ Binding 创建实例返回 nullptr？

核心 DLL 缺失或路径不对。用 Config.WithCoreLibraryDir() 指定目录；确认构建的后端（sdl3/sfml/raylib）与 DLL 匹配；Binding 只链 kernel32，DLL 需随程序分发。

Q4: 为什么没有「暂停/继续」的动画状态机？

LuotiAni 属性 playing 是命令式的：每次置 1 都 play() 复位重播。需要暂停/继续用 C++ API 的 pause()/resume()。

Q5: 怎么让控件在窗口缩放时自动布局？

把控件放进带布局引擎的 Panel（layout: {"type":"h-flow"/"v-flow"/"anchor"/"grid"}），窗口 resize 会自动触发 reflowChildren()。百分比尺寸（"50%"）也随父容器缩放。

Q5b: 界面如何整体适配不同分辨率？

用视口缩放（基准画布 + 缩放模式）：布局按固定基准像素排布（如 1920×1080）， 窗口 resize 时画布整体等比或拉伸适配。

  • C ABI：SetCanvasSize(w, h) 声明基准画布，SetViewportScaleMode(mode) 切换 off / fit / stretch（fit = 等比居中留黑边，stretch = 拉伸铺满）；
  • JSON 布局：顶层 "viewport": {"width":1920, "height":1080, "scale-mode":"fit"} 加载即生效；
  • off 模式为默认：画布跟随窗口，无缩放（原语义，逐像素兼容）。

Q6: 热加载后状态丢了？

热重载会重建整棵控件树，状态不保留。需要保留的状态请存在业务侧（回调里回写），或加载后按 id 重新设置。

Q7: raylib 下多窗口/多实例为什么闪？

raylib 是单窗口架构，只有首个实例有真实窗口，其余 headless。渲染前必须查 UICORN_BACKEND_CAP_MULTI_WINDOW 条件化（headless 实例跳过渲染）。

Q8: 中文显示乱码？

分三层处理：

  1. 文件编码：源码 / 布局 JSON 文件必须保存为 UTF-8 with BOM；
  2. 源码字面量：C++ 代码中的中文字符串必须加 u8 前缀，如 setCaption(u8"提交")——MSVC 默认执行字符集为 GBK，裸中文窄字符串会被转成 GBK 字节导致乱码；
  3. 后端限制：raylib 后端需码点扩展；字体用项目自带 HarmonyOS Sans SC 或按 font 属性指定。

Q9: 控件点击没反应？

依次检查：enabled 是否为 true；是否真的挂到了可见父容器；回调是否注册（SetCallback 事件名拼写）；上层控件是否覆盖（z 序靠后绘制在顶层）；Label 需要 clickable。

Q10: 焦点环怎么去掉？

FocusRingStyle::Solid/Dashed 选样式；设 m_focusRingAlwaysVisible=false 则仅键盘 Tab 聚焦时显示；或调 m_focusRingColor 改颜色。

Q11: 事件回调里能拿到哪些数据？

看事件名对应的负载：text-changed 用 GetTextChanged()，value-changed 用 GetValueChanged()，check-changed 用 GetCheckState()（0/1/2）。通用原始访问器 GetIntVal()/GetFloatVal()/GetDoubleVal()/GetStrVal()/GetPtrVal()。

Q12: 怎么测试我的改动 / 报告 bug？

跑 build_test.bat all sdl3 全量回归；报告问题时附：后端、构建配置、最小复现代码、测试输出（exit 码）。可对照 test/ 中同控件用例的写法。

Q13: 布局文件里的控件找不到？

检查 type 是否为 kebab 小写且已支持（label/button/edit-box/check-box/combo-box/numeric-up-down/progress-bar/scroll-bar/color-picker/text-area/panel/menu-bar/win-frame/splitter）；rect 是否提供；加载返回是否 0（失败）。

Q14: 想用键盘操作界面？

EditBox/TextArea/Slider/Button/CheckBox 默认可聚焦：Tab 切换、Enter/Space 激活（Button 触发 click，CheckBox 循环三态）、方向键调节 Slider/NumericUpDown。Ctrl+Tab 在多窗口间切换焦点作用域。
