5.9 嵌入到你的逻辑回路中

UICornerstone 提供四种集成模式（samples/ 各有完整示例），按「谁托管主循环」区分：

模式目录特点
声明式（hello_uicornerstone）samples/hello_uicornerstone/C ABI + JSON 布局，main() 手写四步循环
命令式（sample_programmatic）samples/sample_programmatic/C ABI 工厂函数程序化建 UI，无 JSON
混合（sample_fromsource）samples/sample_fromsource/核心 DLL + 后端源码编译，AppCallbacks 回调式
显式加载（sample_loadlibrary）samples/sample_loadlibrary/LoadLibrary 手动加载核心 DLL，动态解析导出

5.9.1 嵌入既有主循环（Embedded 模式）

你的游戏/工具已有 while 循环时，把 UI 步骤插进去：

while (running) {
    double dt = timer.tick();

    // 1) 输入：把后端事件喂给 UI
    ui->ProcessEvents();
    // （可选）查询 UI 是否请求退出：ui->IsQuitRequested()

    // 2) 你的游戏逻辑
    world.update(dt);

    // 3) 更新 UI（动画/布局推进）
    ui->Update(dt);

    // 4) 渲染：清屏 → UI → 你的场景（或反之，按遮挡需求）
    ui->Clear();
    ui->Render();       // 绘制控件树
    world.render();     // 你的场景绘制
    ui->Present();      // 交换缓冲
}
UI 渲染可以与你的场景渲染交错：先 Render() 画 UI，再画 3D 场景（UI 在底层）；或先场景后 UI（UI 覆盖顶层）。

5.9.2 AppCallbacks（回调式，核心库直连）

核心库的传统集成方式是 AppCallbacks 接口（include/AppCallbacks.h）+ MainWindow::run()：

#include "AppCallbacks.h"
#include "MainWindow.h"

class MyApp : public AppCallbacks {
public:
    bool onInit() override {
        // BENCH->addControl(...) 构建界面
        return true;
    }
    void onEvent(const Event& event) override { }   // 可选：全局事件钩子
    void onUpdate() override { /* 每帧逻辑 */ }
    void onRender() override { }
    void onQuit() override { }
};

int main() { MyApp app; MAINWIN->run(&app); return 0; }

MainWindow 还提供分步驱动：init(app) / processEvents(app) / update(app) / render(app) / shutdown(app)。

5.9.3 事件泵手工驱动（核心库测试模式）

while (BENCH->isExiting() == 0) {
    MAINWIN->processEvents(nullptr);   // 后端事件 → EventQueue
    BENCH->eventLoopEntry();           // 事件队列出队分派
    BENCH->update();                   // 动画/重复触发
    BENCH->draw();                     // 绘制控件树
}

5.9.4 显式 LoadLibrary（插件式加载）

#include <windows.h>
typedef UIInstance (*CreateFn)(const UIBackendCallbacks*, const UIInstanceConfig*);
HMODULE dll = LoadLibraryA("UICornerstone.dll");
CreateFn create = (CreateFn)GetProcAddress(dll, "UICornerstone_CreateInstance");
UIInstance inst = create(NULL, NULL);
// ... 主循环同 5.4，结束时 FreeLibrary(dll)

这就是 C++ Binding 内部采用的动态加载方案（只链 kernel32，不链 DLL import lib），保证 DLL 版本自由替换。

5.9.5 与你的对象模型对接

  • 数据 → UI：控件属性 set（SetString/SetFloat/...）或 JSON 热加载；
  • UI → 数据：事件回调里更新业务对象（Lambda 捕获 this / shared_ptr）；
  • 多实例：工具窗口 / 调试面板可用第二个 UIInstance（见 5.2）；
  • 多线程：UI 线程模型为单线程事件泵——所有 UI 调用应发生在主线程；跨线程发消息请自行转发（如 std::async + 主线程轮询队列）。
  • 分辨率适配：以固定基准画布排布（如 1920×1080），窗口 resize 时用视口缩放整体适配： SetCanvasSize(w, h) 声明基准画布 + SetViewportScaleMode(off|fit|stretch) 切换模式（fit = 等比居中留黑边，stretch = 拉伸铺满，off = 画布跟随窗口，默认）。 命中 / 焦点 / 弹窗钳制随根变换自动换算，无需业务侧处理。完整用法见 5.6 视口画布缩放。
