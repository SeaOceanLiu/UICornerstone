3.7 洛蒂动画

LuotiAni 是 UICornerstone 内置的关键帧动画引擎：JSON 描述动画（类似 Lottie 的简化版），运行时烘焙为帧贴图，播放只做查表，性能极高。播放速度由真实毫秒驱动，与渲染帧率无关。

3.7.1 一个最小动画文件

{
  "overview": {
    "version": "1.0", "name": "rotateBtn",
    "view": { "width": 256, "height": 256 },   // 画布尺寸
    "frameRate": 60,                            // 帧率（不得为 0）
    "totalFrames": 30,
    "loop": true                                 // 必填
  },
  "layers": [
    {
      "name": "logo", "type": "image",
      "src": "images/logo.png",                  // 相对资源根路径；亦支持 "provider:资源ID"（内存加载）
      "keyFrames": [
        { "frame": 0, "operation": [
          { "type": "translate", "tx": 0, "ty": 0 },
          { "type": "scale", "sx": 1.0, "sy": 1.0 },
          { "type": "opacity", "opacity": 100 } ] },
        { "frame": 30, "operation": [
          { "type": "rotate", "angle": 360, "cx": 128, "cy": 128,
            "easing": "ease-in-out" } ] }
      ]
    }
  ]
}

3.7.2 关键帧语法要点

层级键说明
缓动easinglinear（默认）/ ease-in / ease-out / ease-in-out / quad / sine / cubic / cubic-bezier(x1,y1,x2,y2)
keyFramesframe帧号（第 0 帧关键帧必须存在）
frameRate / totalFrames / loop帧率（≠0）、总帧数、循环开关（必填）
opacity / blendMode图层级透明度；混合模式 normal / additive / additive-premultiplied / modulate / blend / blend-premultiplied / multiply
轨迹path仅 translate：bezier（c1/c2 控制点）/ parabola（vx,vy 初速）/ catmull-rom（points）
src / width / height图片资源路径；显式宽高可拉伸，缺省用贴图原始尺寸。支持 provider: 资源 ID（如 "src": "provider:marker"，经内存 provider 加载；未命中回退文件系统并记录日志——P0-79）
operationtranslate / scale / rotate / opacity / visible{tx,ty} 增量累加 / {sx,sy} 累乘 / {angle,cx,cy} / {opacity 0-100} / {visible}
layertypeimage（完整支持）；shape/text 解析支持但烘焙跳过
overviewview画布 {width,height}，w/h 传 0 创建时回退到画布尺寸

3.7.3 加载与播放（C++）

#include "LuotiAni.h"

auto demo = LuotiAniBuilder(BENCH.get())
    .loadAniDesc("animations/rotateBtn/rotateBtn.jsonc")
    .setRect(SRect(20, 20, 256, 256))
    .prepare()              // 烘焙全部帧贴图（未加载会抛异常）
    .setAutoStart()         // 构建后自动播放
    .build();
demo->create();
BENCH->addControl(demo);

demo->pause();              // 暂停
demo->resume();             // 从暂停处继续
demo->play();               // 复位到第 0 帧重播
demo->setLoop(false);
demo->setFrame(15);         // 跳帧（仅已 prepare 且帧号合法）
printf("frame=%u/%u, playing=%d\n",
       demo->getCurrentFrame(), demo->getTotalFrames(), demo->isPlaying());

3.7.4 属性系统 / C ABI

// C ABI
UIControlHandle ani = UICornerstone_CreateAnimation(g_inst, "tA1.jsonc", 20, 20, 256, 256, 1.0f, 1.0f);
UICornerstone_SetBool(g_inst, ani, "playing", 1);   // 置 1 = play()（帧复位重播）；置 0 = pause()
UICornerstone_SetBool(g_inst, ani, "loop", 1);
UICornerstone_SetInt (g_inst, ani, "frame", 10);    // 跳帧

// C++ Binding
Control ani = ui->CreateAnimation("animations/breath/breath.jsonc", 20, 20, 0, 0);
ani.SetBool(PropertyNames::kPlaying, true);
ani.SetBool(PropertyNames::kLoop, true);
属性类型说明
animationString动画描述路径（只写不读）；加载+prepare，播放中则从第 0 帧重播
frameInt跳帧（未 prepare 拒绝）
loopBool循环开关
playingBool命令式：置 1 = play()，置 0 = pause()；未 prepare 置 1 拒绝

3.7.5 在 Button 上挂动画（JSON 布局）

{
  "type": "button", "id": "animatedBtn",
  "rect": { "x": 40, "y": 40, "w": 120, "h": 40 },
  "caption": "Rotate",
  "luotiAni": "assets/animations/rotateBtn/rotateBtn.jsonc"
}
多实例共享：同一动画文件的多个播放器共享烘焙帧数据（LuotiInstance 机制），内存仅一份。

luotiAni 键内嵌的动画不自动播放：挂树后经 Button::setRenderDevice 自动延迟 prepare（加载阶段无渲染设备、prepare 自然延迟到设备就绪），之后 SetBool("playing")=1 启动。 编程式等价写法：C ABI UICornerstone_CreateAnimatedButton(inst, jsonc, x, y, w, h, xScale, yScale) 或 Binding ui->CreateAnimatedButton(jsonc, x, y, w, h)——内嵌动画构造 scale 恒 1.0， 两个 scale 参数作用于按钮本身（双重缩放陷阱见 5.5 控件缩放）。

动画结束事件：非循环播放到最后一帧后触发 AnimationEnded 自定义事件（C ABI 回调链路暂未适配）。
