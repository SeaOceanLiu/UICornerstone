3.3 属性系统

UICornerstone 的控件不暴露成百上千个 setter/getter，而是统一通过命名属性读写。这一设计让三层接口（C++ 直接 API、C ABI、C++ Binding）共用同一套语义，也让 JSON 布局与属性读写天然同构。

3.3.2 属性名与事件名常量

所有属性名/事件名字符串集中在 include/PropertyNames.h，C++ Binding 直接用这些常量，杜绝手写字符串出错：

label.SetString(PropertyNames::kCaption, "Hello");          // "caption"
label.SetEnum(PropertyNames::kAlign, "center");             // "align" = "center"
checkBox.SetEnum(PropertyNames::kCheckState, "checked");    // "check-state" = "checked"
slider.SetFloat(PropertyNames::kValue, 50.0f);              // "value"
button.SetCallback(PropertyNames::kEventClick, [](const Event&){});
editBox.SetCallback(PropertyNames::kEventTextChanged, [](const Event& e){
    auto text = e.GetTextChanged();
});
label.SetString(PropertyNames::kFontResource, "maple-font");           // "font-resource"：内存注册字体 ID
label.SetString(PropertyNames::kFontFile, "fonts/MyCustom.ttf");       // "font-file"：任意字体文件路径

3.3.3 属性在控件中的实现

每个控件以 setXxxProperty / getXxxProperty 覆写实现分发；未实现的属性返回 0。颜色属性支持带状态子键的 StateColor：

// C ABI：设置按钮四态背景
UICornerstone_SetStateColor(g_inst, btn, "background",
    (UIStateColor){ stateNormal, stateHover, statePressed, stateDisabled });

// C++ Binding
button.SetStateColor("background",
    UIStateColor{ UIColor{64,96,160,255},  // normal
                  UIColor{80,128,192,255}, // hover
                  UIColor{48,80,144,255},  // pressed
                  UIColor{80,80,80,255} }); // disabled

3.3.4 回调属性

事件回调也走属性通道，统一为 SetCallback(instance, ctl, eventName, cb, userData)：

// C ABI
UICornerstone_SetCallback(g_inst, btn, "click",
    [](void* ctl, const void* data, void* user){ printf("clicked\n"); }, NULL);

// C++ Binding（事件名常量 + std::function）
button.SetCallback(PropertyNames::kEventClick, [&](const Event& e){
    // 事件负载用具名访问器读取
});

事件名全集：click、enter、confirm、cancel、close、text-changed、check-changed、value-changed、selection-changed、color-changed、position-changed、moved、select、expand、collapse。

3.3.5 只读与命令式属性

部分属性是只写（set 生效、get 不支持）或命令式的：如 image（图片路径，加载后不复读）、LuotiAni 的 playing（置 1 即 play()）、animation（加载动画描述）。使用时以控件页的属性表标注为准。
