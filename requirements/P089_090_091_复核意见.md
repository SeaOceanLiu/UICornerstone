## 1. 补充 1：P0-91③ `TabMovePage` 建议补一条显式语义

`m_currentIndex` 重映射建议在设计/测试中写明规则：**当前页 == 被移动页 → 跟随其新位；当前页处于 `(from, to]` 区间 → 反向偏移 ±1**。设计器侧会显式回设当前页（跟随被选页），但引擎内部规则明确后测试断言更可读。

## 2. 补充 2：P0-91① `TabGetItemRect` 坐标域注明

`tabRect` 为 **TabControl 局部逻辑坐标**——建议 Binding/文档注明；设计器将经 Tab 全局原点换算（与既有 globalOriginOf 体系一致）。

## 3. 补充 3：P0-90 键名与设计器行型确认

- 三态 + 可选两键（Q-2 建议**一并给**，避免二次同步）；
- 均为**单色**（非四态）——设计器行型 = 每键一个 ColorPicker 行（行池 key `xcolor:tab-*`），extended 持久化、导入/导出/预览全链随带；
- 同步后设计器将复核 tTabs 的亮色文字默认（P0-90 使页签底可配后，浅底 + 亮字需用户可调——现有四态文字行已覆盖）。

## 4. 补充 4：P0-89 日志建议

`lookupHandler` 的 warn 文案含 **control id**（设计已含 ✓）；建议对同一 handler 名在**同次 LoadLayout 内去重**（避免 20 处调用点对同一缺失名刷屏）——低成本、可选。
