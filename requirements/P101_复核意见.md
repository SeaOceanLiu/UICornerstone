## 补充/勘误

1. **设计器合成探针需同步改指针式布局**（文档 §5 已注明 ✓，落实到实施清单）：设计器 `auto=1` 的合成推送当前按内联布局写 `ue.data`（`snprintf` 前 120B ✗）——同步后改为：
   ```cpp
   UIEventDropFile df{};
   const std::string p = "Temp/drop_probe.csd";   // 调用期间保活 ✓
   df.path = p.c_str(); df.isText = 0;
   std::memcpy(ue.data, &df, sizeof(df));
   ue.type = UI_EVENT_DROP_FILE;
   ```
2. **桥缺口完整性观察**：同一 switch 亦无 `WindowMoved`（SDL 映射侧有 ✓）——若引擎有依赖窗口移动事件的功能同受影响 ✗（推测当前未使用）；建议顺手核查，若无依赖可不动（不扩面）。
3. `UI_EVENT_DROP_FILE_DATA` 宏在指针式布局下语义不变（`(const UIEventDropFile*)ev->data`）✓——头注释同步更新即可（§3.6 ✓）。
4. 验收矩阵建议补一条：**指针式合成（宿主约定）**——`PushUIEvent` 后立即释放/覆盖源字符串，回调仍应拿到正确路径（验证"立即拷贝"语义 ✓，防未来误改异步化）。
